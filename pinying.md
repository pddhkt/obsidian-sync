  ```
  fcitx5 -r

  This restarts the fcitx5 daemon. The -r flag means "replace" - it stops the currently running fcitx5 process and starts a
  new one with the updated configuration. This lets you reload config changes without logging out.

  Opening the fcitx5 configuration tool

  fcitx5-configtool

  Or run it in the background:
  fcitx5-configtool &

  This opens the GUI where you can add/remove input methods like Pinyin (Rime).
  ```
