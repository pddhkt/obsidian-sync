# 內容製作 (Add-on)

> 一條龍內容輸出:Blog、PDP 文案、SEO meta、Social caption,一個 tone,一個 voice。

## 解決咩問題
- 客戶 Google「電飯煲推薦」搵唔到 Imarflex,organic 上限低
- 「伊瑪生活」blog 區開咗,冇人持續寫
- 200+ SKU,人手寫 PDP 文案太慢,新品上市拖到 launch 慢
- 唔同人寫,tone 唔統一,品牌感散
- Social caption / SEO meta 經常臨急臨忙補,質素參差

## 帶嚟咩好處
- **Blog organic 6-12 個月變 top 渠道** (每篇 blog 係永久資產,寫一次排幾年)
- **新品上架快 5-10x** (幾日 → 同日出,PDP + SEO meta + social caption 一次過齊)
- **品牌 voice 統一** (同一套 brand kit,Blog / PDP / Social 一個 tone)
- **Cross-sell 自然** (blog「氣炸鍋整燒肉」→ 直接連 IAF-30E PDP)
- **品牌權威感** (50 年 know-how,長期累積)

## 做緊乜
**1. Blog 內容 (月度持續)**
5 大主題 cluster:
1. 食譜
2. 選購攻略
3. 產品比較
4. 保養貼士
5. 新品介紹

**2. PDP 文案量產 (按 SKU on-demand)**
你出 spec / 賣點,我哋出:
- PDP 標題
- Hook + Benefit + Spec + Trust + Social proof 五段式
- SEO meta title + description
- URL slug
- 配套 social caption (IG / FB)

**3. Brand voice 統一**
全部跟 [[../brand/voice-tone-of-voice|brand voice]] + [[../brand/voice-pdp-copy-framework|PDP framework]] 出,唔會散。

## 適合幾時加
- **Q1 launch 即時開始 Blog** — SEO 有滯後效應,越早累積越好,一停就重新 build momentum
- **Q2-Q3 加埋 PDP 量產** — Launch 後 SKU backlog 開始堆積,呢陣加最抵
- 即使 budget 緊,都建議起碼開 Light blog tier

## 報價

**Blog 月費 (3 tier)**

| Tier           | 頻率      | 月費        |
| -------------- | ------- | --------- |
| Light          | 2 篇 / 月 | ~HK$500   |
| **Standard** ⭐ | 4 篇 / 月 | ~HK$1,000 |
| Aggressive     | 6 篇 / 月 | ~HK$1,500 |

**PDP 文案 (on-demand)**
- Setup: HK$2,000 (brand voice kit 整合 + 首批 template)
- 月費:折入 Standard blog tier 嘅 retainer,SKU 用量計
- 大 batch (50+ SKU 一次過) 可單獨報價

**典型組合:HK$2,000 setup + HK$3,500/月**(Standard blog + PDP retainer)

## Pitch 講法
> 「你出 spec,我哋出文案 — blog、PDP、SEO meta、social caption,一個 tone,一個 voice。SKU 幾多都頂得住。Blog 唔係 marketing 開支,係資產投資;PDP 唔係文書工作,係轉化率。兩邊一齊做,先夠槓桿。」
