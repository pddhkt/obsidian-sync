# 訂閱式重複購買產品 (Add-on)

## 解決咩問題
- 配件 / 濾芯 / 清潔劑係必需品,但客戶要記住返嚟買
- 流失客戶其實只係忘記,唔係去咗 buy 競爭對手
- 月度 recurring revenue = 0

## 帶嚟咩好處
- 月度可預測 recurring revenue (cashflow 好正)
- LTV +30-50% (訂閱客平均留 12-24 個月)
- 庫存可預測
- 訂閱專屬折扣 (-10%) 變鎖客 hook

## 候選 SKU (要 brainstorm)
- 空氣清新機濾網
- 吸塵機 HEPA filter
- 電熱水壺除水垢檸檬酸
- 空氣炸鍋油刷 / 烘焙紙

## 🟠 Open question (blocker)
**Airwallex 香港版本支唔支援 recurring billing?** → see [[decision-airwallex-recurring]]
**邊啲 SKU 有 consumable?** (client 要列)

## 適合幾時加
**Q3 加最好** — 有一年數據先知邊啲產品啱

## 報價
- Setup: HK$8,000-15,000
- 月費: $0 (自家系統)

## Pitch 講法
> 「客戶買咗空氣清新機,3 個月後濾網要換。佢哋唔知,你又冇追。訂閱模式自動每 3 個月寄一個,客戶慳事,你有 recurring。」
