# Channel Production Workflow

一個好 topic 唔應該只出一篇 blog。先用 blog 建 SEO asset,再拆成 Instagram / Facebook,最後將 customer response 帶返去下一輪 research。

## One topic, multiple outputs

| Output | Role | Example |
|---|---|---|
| Blog | Search asset, long-form answer | `點揀電飯煲:IH、微壓、球釜一篇講清楚` |
| Instagram carousel | Visual explanation, save/share | `5 張圖睇懂 IH vs 微壓` |
| Facebook post | Link distribution + trust | Blog summary + link + CTA |
| Story / short update | Reminder / poll / Q&A | `你屋企幾多人食飯?` |
| FAQ / support snippet | Reduce repeated questions | `保養點登記?` |

## Blog checklist

Before drafting:

- [ ] Topic scored in [[topic-research-workflow]]
- [ ] Primary / secondary keywords filled in [[seo-keyword-research]]
- [ ] Search intent confirmed
- [ ] Destination / CTA selected
- [ ] Internal links selected
- [ ] Image needs listed

Blog structure:

```markdown
# SEO title

Intro: answer search intent quickly.

## H2: Main answer / buying decision

### H3: Key point 1

### H3: Key point 2

### H3: Key point 3

## Product / use-case recommendation

## FAQ

## CTA
```

## Instagram workflow

Use IG when the topic can be made visual or easily saved.

| Carousel frame | Purpose |
|---|---|
| 1 | Hook / problem |
| 2 | Product or scenario |
| 3 | Main teaching point |
| 4 | Comparison / step / tip |
| 5 | Soft CTA |

IG caption should include:

- 1 short hook
- 2-4 helpful bullet points
- Product / category mention
- Soft CTA
- 3-8 relevant hashtags

## Facebook workflow

Use FB for:

- Blog link distribution
- Product education for broader audience
- Promotion / launch support
- Customer trust and support content

FB caption structure:

```markdown
Hook:
Context:
Useful takeaway:
Link / CTA:
```

## Repurposing rules

- Blog = complete answer
- IG = visual summary, saveable
- FB = discussion / link / trust
- FAQ = repeated questions
- PDP copy = product-specific benefit

Do not copy the same caption to every channel. Keep the idea same, but angle should match channel behavior.

## Production handoff

Every approved topic brief should include:

| Field | Needed for |
|---|---|
| Blog title + outline | Writer / SEO |
| Keyword + intent | SEO review |
| CTA + destination | Conversion |
| IG frame outline | Designer / social producer |
| FB caption angle | Social scheduler |
| Asset list | Photography / image generation |
| Publish date | Calendar |
| KPI | Report |
