# Blog

> Imarflex 內容團隊嘅 blog 工作區 —— drafting reference + sample posts。

## What lives here

- `samples/` — 編輯範本同 sample blog posts。目前 3 篇 draft,每篇對應一個 content cluster + 一個 angle/tone:
  - 食譜 — `recipe-air-fryer-shrimp-toast-cha-siu.md`
  - 選購攻略 — `buying-guide-rice-cooker-2026-ih-vs-pressure.md`
  - 保養貼士 — `maintenance-summer-fan-deep-clean-guide.md`
- `samples/images/` — 每篇文嘅 GPT-image generated 插圖,按主題前綴命名。
- `samples/_readme.md` — 詳細 index table + image 清單 + 待補 clusters。

## Naming convention

- kebab-case、undated filename;cluster 寫喺 frontmatter (`cluster:`),日期寫喺 `created:`。
- 圖片放 `images/`,前綴對應該篇主題。

## Do NOT put here

- 策略 / voice / content pillars 定義 → 放 `brand/` (`content-pillars`, `voice-tone-of-voice`, `content-blog-direction`)。
- Go-live / 廣告 asset kits → 放 `online-marketing/sales-content/<campaign>/assets/`。
- 已發佈 social posts → 放 `online-marketing/sales-content/cycles/<yyyy-mm>/posts/`。
- 呢度只放 blog 文稿同其插圖。
