# Content Calendar

呢個 calendar 用嚟安排 SEO research、blog production、Instagram、Facebook、review 同 refresh。實際 topic brief 放入 [[content-briefs/_readme|content-briefs]],已發佈紀錄放入 [[published-content/_readme|published-content]]。

> [!info]
> 上面講嘅係 planning。真正喺 imarflex-app CMS calendar 上面 create post、收 per-post / per-image feedback、iterate 到 confirm、deliver 嘅操作流程,睇 [[cms-content-pipeline]](API 機制喺 `imarflex-cms` skill)。

## Planning levels

| Level | 用途 | Output |
|---|---|---|
| Quarterly | 定 SEO direction、priority categories、content gap | SEO roadmap |
| Monthly | 決定 4-8 個 topics、blog/social mix | Monthly content plan |
| Weekly | 實際 production、review、schedule | Weekly task list |
| Daily / posting day | Publish、reply、track engagement | Published record |

## Monthly content mix

Standard 建議每月:

| Channel | Frequency | Purpose |
|---|---:|---|
| Site blog | 4 posts / month | SEO asset + PDP traffic |
| Instagram | 8-12 posts / month | Visual product education + lifestyle |
| Facebook | 4-8 posts / month | Link distribution + promotion + customer trust |
| Stories / short updates | Optional weekly | Reminder, poll, product Q&A |
| Refresh old content | 1-2 pages / month | Improve existing rankings |

## Weekly production rhythm

| Day | SEO / research | Content production | Publishing / review |
|---|---|---|---|
| Monday | Gather signals, review GSC / site search | Confirm weekly topics | Check previous week performance |
| Tuesday | SERP review, keyword mapping | Blog outline / brief | Prepare asset list |
| Wednesday | Internal links / CTA mapping | Blog draft + IG carousel copy | FB caption draft |
| Thursday | SEO checklist | Edit, image brief, final caption | Schedule posts |
| Friday | Add notes to report | Publish / approve next week | Update published-content log |

## Status values

Use consistent status when planning:

- `idea`
- `researching`
- `brief-ready`
- `drafting`
- `editing`
- `scheduled`
- `published`
- `refresh-needed`
- `archived`

## Review points

每月底要檢查:

- Blog impressions / clicks / CTR from GSC
- Blog to PDP / collection clicks
- Instagram reach, saves, shares, profile clicks
- Facebook reach, link clicks, comments
- Top customer questions from published content
- Topics that should become FAQ / support page
- Old articles that need refresh
