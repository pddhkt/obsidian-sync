# SEO Keyword Research

SEO research 要幫每個 topic 回答 4 件事:

1. 目標讀者 search 緊咩字
2. Google 對呢個 keyword 想要咩內容格式
3. Imarflex 有冇產品 / expertise / CTA 可以接住
4. 內容做完之後點追蹤成效

## Topic SEO worksheet

每個準備寫嘅 topic 都要填一次。

| Field | Notes |
|---|---|
| Topic name | 例如 `氣炸鍋蝦多士做法` |
| Primary keyword | 文章最主要排名字 |
| Secondary keywords | 相關字、問題字、同義詞 |
| Search intent | Informational / commercial / transactional / navigational |
| SERP format | Blog、PDP、forum、video、recipe、comparison |
| Target destination | PDP、collection、parts finder、warranty、WhatsApp |
| CTA | 讀者睇完下一步做咩 |
| Internal links | 至少 2 條內鏈 |
| Social reuse | IG carousel、FB post、short caption |
| KPI | Impressions、CTR、ranking、PDP clicks、engagement |

## SEO research steps

### 1. Start from business priority

唔好由 search volume 開始。先由今季 priority category / SKU / customer issue 開始。

Example:

| Business priority | Seed keyword | SEO topic |
|---|---|---|
| 推 IH 電飯煲 | IH 電飯煲 | `2026 點揀電飯煲?IH、微壓、球釜一篇講清楚` |
| 夏天推風扇 | 風扇清潔 | `風扇換季深層清潔:拆網、抹扇葉、安全注意事項` |
| 減少客服查詢 | 伊瑪牌保養 | `Imarflex 保養點登記?購買後 5 分鐘完成教學` |

### 2. Expand keyword patterns

| Pattern | Example |
|---|---|
| `產品 + 推薦` | `氣炸鍋推薦` |
| `產品 + 點揀` | `點揀電飯煲` |
| `產品 + 問題` | `風扇好嘈` |
| `產品 + 場景` | `細廚房氣炸鍋` |
| `產品 + 比較` | `IH vs 微壓` |
| `品牌 + 服務` | `伊瑪牌保養` |
| `產品 + 清潔 / 保養` | `電飯煲內膽清潔` |

### 3. Check SERP manually

每個 primary keyword 都要做一次手動 SERP review。

- 用 incognito / clean browser search
- 記低 top 10 result 係咩格式
- 睇 People Also Ask / related searches
- 睇本地香港結果多唔多
- 睇 competitor 有冇內容缺口
- 判斷要寫 blog、comparison、recipe、FAQ 定 support page

SERP note format:

```markdown
## SERP notes

- Keyword:
- Date checked:
- Top result types:
- Strong competitors:
- Weak / outdated result:
- People Also Ask:
- Related searches:
- Content format needed:
- Imarflex angle:
```

### 4. Map keyword to destination

每個 keyword 都要有 business destination。冇 destination 嘅 keyword,通常唔應該排高 priority。

| Keyword intent | Destination |
|---|---|
| Buying guide | Collection / priority PDP |
| Comparison | Comparison section + PDP |
| Maintenance | Parts finder / warranty / support |
| Recipe | Product PDP + related recipe cluster |
| Branded service | Warranty registration / support page |
| Troubleshooting | FAQ + relevant product / replacement part |

### 5. Write SEO requirements before drafting

| Requirement | Rule |
|---|---|
| Title | Primary keyword near front, under 60 Chinese chars if possible |
| Meta description | Include primary / secondary keyword + clear value |
| URL slug | Short, kebab-case, English preferred |
| H2/H3 | Match search questions and SERP format |
| Internal links | 2+ links to PDP / collection / related blog |
| Image alt | Describe product / step / result clearly |
| Schema idea | Recipe, FAQ, HowTo, Product, Article when suitable |
| CTA | Soft CTA at bottom, not hard sell at opening |

## Topics to avoid or de-prioritize

- Search volume 高但同 Imarflex 產品弱相關
- 純百科式內容,冇 PDP / support / business destination
- 需要醫療、安全、能源效益絕對 claim 但冇資料支持
- 只係追 competitor brand,但冇中立比較角度
- 寫完只會有 traffic,但唔會幫 funnel
