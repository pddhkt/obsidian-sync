# IFQ-22R - V7 Concept-Only Illustrated Airflow Ribbon

This pass replaces the earlier V7 modern-design test. It removes visible frame numbers and tests a clearer illustration system:

**Product cutout + flat HK home illustration + one recurring blue airflow ribbon.**

## Why This Exists

The previous V7 still felt like a clean template around a generated lifestyle/product image. This pass tests whether the carousel can feel more distinctive by letting illustration carry the story while the product stays as a replaceable cutout/module.

The intended future production path is:

1. Approve the illustration language and content composition with a generic product placeholder.
2. Replace the placeholder with real IFQ-22R client/product-reference imagery.
3. Apply exact Traditional Chinese text with deterministic local layout if punctuation or typography must be exact.

## Concept Rules

- No visible frame numbers.
- Do **not** use real IFQ source images in this concept pass.
- Use a generic unbranded white compact air-circulator placeholder.
- Judge illustration style, hierarchy, air-ribbon identity, and carousel feel.
- Do not judge product accuracy from these files.
- No fake logo, model number, QR code, price, URL, warranty badge, or readable product labels.

## Style Direction

**Product + Flat HK Home Illustration + Airflow Ribbon**

- Semi-realistic product cutout placed into a flat/vector-like illustrated Hong Kong home.
- Clean illustrated furniture, curtains, window, coffee table, and abstract HK towers.
- One expressive Cool Air blue ribbon becomes the recurring visual identity.
- Small warm orange heat/stuffy patch can show the problem state.
- Rice White, Heritage Blue, Cool Air blue, Soft Charcoal, Clay Beige, warm daylight cream.
- No paper collage, no taped notes, no big frame numbers, no blueprint grid, no cartoon mascot.
