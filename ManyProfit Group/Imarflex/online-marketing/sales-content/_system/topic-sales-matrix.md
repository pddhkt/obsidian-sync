# Topic Type to Sales Purpose Matrix

This note makes the strategy visible. The monthly plan should not only say "post on IG / FB"; every post should show topic type, sales purpose, channel format, and CTA.

## Matrix

| Topic type | Main sales purpose | IG content example | FB content example | Best CTA | Ad fit |
|---|---|---|---|---|---|
| buying-guide | decision-confidence | Carousel: capacity table / feature checklist | Blog link post: full guide summary | View collection / PDP / WhatsApp advice | Retargeting after blog traffic |
| comparison | decision-confidence | Carousel: A vs B differences | Link post: comparison article | Compare models / view PDP | Retargeting or sales campaign if product page is ready |
| problem-solution | lead-capture | Carousel: "problem -> fix" checklist | FAQ post with support link | WhatsApp / FAQ / parts finder | Retargeting if problem implies purchase intent |
| recipe-use-case | product-discovery | Reel: cooking demo / carousel recipe | Weekend recipe link post | View product category | Boost only if organic save/share is strong |
| maintenance-how-to | trust-reduction | Reel or carousel: cleaning steps | Safety / maintenance guide post | Parts finder / warranty / replacement product | Usually no ad unless tied to seasonal promo |
| product-proof | direct-purchase | Reel: product demo, dB, capacity, feature proof | Product explanation post with offer | PDP / add to cart / WhatsApp | Strong paid candidate |
| trust-service | trust-reduction | FAQ carousel / Story Q&A | Warranty / support link post | Warranty registration / WhatsApp | Retargeting candidate |
| promotion | direct-purchase | Offer post / Story countdown | Offer link post | Promo PDP / collection / checkout | Strong paid candidate |

## Rule of thumb

- Use **IG** when the customer needs to see or save something: table, checklist, recipe, demo, FAQ.
- Use **FB** when the customer needs context, a link, trust, or offer details.
- Use **ads** only when the destination and tracking are ready.

## Coverage target per month

| Coverage               |                   Minimum target |
| ---------------------- | -------------------------------: |
| Topic types used       |                                4 |
| Sales purposes used    |                                3 |
| IG posts               |                             8-12 |
| FB posts               |                              4-6 |
| Direct-purchase posts  | 1-2 only, unless promo is active |
| Trust / decision posts |           At least 50% of output |
