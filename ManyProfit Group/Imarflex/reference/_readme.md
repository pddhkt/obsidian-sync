# Reference — Long-form narrative source-of-truth

The full prose strategy + methodology library for the Imarflex 伊瑪牌 pitch. This is the "read the full strategy" shelf the vault `_index.md` links into — narrative docs, not the structured `.base` catalogues.

## What lives here

**Pitch core (May 2026, Cantonese):**
- `internal-master.md` — 16-section internal master spec (decision legend 🟢🔵🟡).
- `pitch.md` — client-facing 數碼銷售策略方案書 (rendered as the HTML deck in `../pitch/deck/`).
- `add-ons-discussion.md` — per-add-on negotiation (4-question format).
- `funnel-demo-spec.md` — HTML/iframe funnel-slide layout spec.

**Methodology + research layer (English, YAML frontmatter):**
- `methodology-summary.md` — the 7-step workflow.
- `2026-strategy-benchmark.md` — point-in-time industry benchmark (re-run ~every 6 months).
- `session-decisions-2026-05.md` — decision-rationale log for the May sprint.
- `external-research-imarflex.md` — public brand research (status: draft).

## Naming convention

Topic-based filenames; time-sensitive logs/benchmarks carry the period in the name (`*-2026-05`, `2026-*`).

## Do NOT put here

Structured catalogues (use `_features.base` / `_addons.base` / `_open-questions.base`), rendered slides (`pitch/deck/`), or final brand assets (`brand/guideline/`).
