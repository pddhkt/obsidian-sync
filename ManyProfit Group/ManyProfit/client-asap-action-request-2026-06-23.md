# Client ASAP Action Request — 2026-06-23

> [!note]
> Based on the latest quotation **IMX-2026-Q02** and the launch timetable. The main message: target go-live is still **mid-July 2026**, but the schedule is gated by client handover during **2026-06-23 to 2026-06-29**.

## Sendable Message

Hi Derek，

跟返今次報價單同上線時間表，兩個網站其實已經有基礎可以推進；而家最重要係你哋盡快提供啟動資料，因為 **產品資料 / DNS / 收款 / email** 會直接影響 7 月中上線時間。

麻煩你哋今個星期（2026-06-23 至 2026-06-29）優先處理以下幾項：

1. **確認合作 + 簽署報價單 + 付款方式**  
   請確認付款方式（50/30/20 或 50/50），簽回報價單，並安排 50% 訂金 **HK$22,500**。

2. **兩個網域 / DNS 管理權**  
   需要 Imarflex + Many Profit 兩個 domain 的 GoDaddy / DNS 管理權，用來設定網站上線、email 驗證、redirect 等。

3. **產品資料 / SKU（最重要 gate）**  
   請提供產品 CSV / Excel，包括產品名、圖片、規格、價錢、SKU code、庫存狀態、margin。如果有現成 product photo / spec sheet，請一併提供。

4. **品牌素材**  
   Many Profit 及旗下品牌 logo、色彩、字型、品牌介紹；如有 About Us、政策、FAQ 文案，也可以一併交給我。

5. **Airwallex 申請資料**  
   請準備公司註冊證書、授權人身份證、UBO 文件。Airwallex 批核通常要時間，所以越早開始越穩陣。

6. **Email 安排**  
   請確認每個網站的寄件地址（from-address）、客戶回覆 inbox（reply-to）、以及而家用緊邊個 email host（例如 Microsoft 365 / Google Workspace / 其他）。

7. **Shopline 遷移方向**  
   請確認想新舊站並行一段時間，定係 7 月中直接 cutover 到新站。如可以，請同時準備 Shopline 產品 / 圖片 / URL export。

8. **未來 90 日 promo / 活動時間表**  
   如果有節日推廣、新品、折扣、campaign，請先交一個 rough calendar，方便我哋排 6 個月推廣 trial 的內容。

如果以上資料今個星期內可以開始交，我哋就可以同步做：產品匯入、網站微調、Resend email 驗證、Airwallex 接線、上線前 QA。  
如果產品資料、Airwallex 或 DNS 任何一項延遲，上線日都有機會順延。

我建議可以先交「已有版本」，不需要等到 100% 完美；我哋可以邊入資料邊補齊，避免時間卡住。

Thanks,  
Jack
