# TimeKids — Timi's Hamster House Home Hub

## Concept

The home screen should be **Timi's hamster house/playground**, not a generic menu.

Children navigate by tapping rooms, tunnels, toys, windows, shelves, and little objects that open story worlds.

## Why this works

- A hamster house is naturally playful for ages 4–6.
- It gives Timi a recognizable home base.
- It makes the app feel like a place to explore, not a content library.
- It supports stickers, unlocks, decorations, and progression later.
- It keeps story navigation visual and low-reading.

## Home hub structure

| House area/object | Possible story link |
|---|---|
| Sand corner / little pyramid toy | Ancient Egypt |
| Lantern shelf / kite toy | Ancient China |
| Harbour window / tiny boat | Hong Kong Old Harbour |
| Map tunnel | Silk Road |
| Clay figure shelf | Terracotta Army |
| Mini sports ring | Greek Olympics |
| Road/bridge track | Roman Roads |
| Little ship bath/toy | Viking Ships |
| Workshop desk | Leonardo's Workshop |
| Rocket corner | Moon Landing |

## Navigation rules

- Every story entry should be a large visual object, not a small text button.
- Timi should point, wave, or react when a tappable story object is highlighted.
- Completed stories get a sticker/decor added to the house.
- Locked or coming-soon stories should look gentle and exciting, not frustrating.
- Adult gate/settings should stay small and away from the main child path.

## V1 home hub

For v1, the house does not need complex simulation.

Minimum:

- one illustrated hamster house/playground scene,
- 10 tappable story objects,
- Timi idle animation/pose,
- completed sticker/decor state,
- replay/greeting button,
- mute/settings/adult gate.

## Later progression

Later, the house can become a retention system:

- children earn decorations from each story,
- parent can see the sticker collection,
- Timi's house changes as the child learns,
- seasonal rooms or content packs can appear as new house areas.
