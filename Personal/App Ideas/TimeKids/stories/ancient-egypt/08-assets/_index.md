# Ancient Egypt Assets

This folder stores generated and selected image assets for the Ancient Egypt private beta demo.

## Rule

- Scene-specific images live under the matching scene folder.
- Shared story images live under `shared/`.
- `generated/` stores all image attempts.
- `selected/` stores current app/story choices.
