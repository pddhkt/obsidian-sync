Structures → Systems

The site treats my work as one continuum: from designing physical structures that must stand up to engineering software systems that must bear real-world use. It's presented like an engineer's drawing set — but kept clean and modern, so it reads as a builder with an engineer's discipline, not a civil-engineering firm.

03 · Motion — the scroll means "construction"

Plot, don't fade. Lines stroke on from 0→full (like a plotter drawing), dimension lines extend, annotations write in.
Assemble on the Journey. A tower builds floor-by-floor as you scroll — each role adds a level. Echoes your 39-storey towers.
Grid parallax. The blueprint grid drifts subtly behind content for depth.
Precise easing. No bounce, no overshoot. Quick, deliberate, engineered.
Calibration: the metaphor lives in the chrome (annotations, grid, sheet tags, title block, motion) and the Journey page — while the content always leads with software & product. You feel "rigorous engineer-builder," never "this is a civil engineer." That keeps engineering a supporting thread, as you chose.
