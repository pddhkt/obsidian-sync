02 · What it means

  • The schedule format — on a drawing set, every fixture, beam and fitting is catalogued in a schedule with a tag. Here the stack is the schedule: tools as equipment with codes you can point at.
  • The TAG codes — FE-01 … EN-05. A tag per discipline (FE / BE / CL / TL / EN) so the page reads like a parts list, not a logo wall.
  • Disciplines, not buckets — Frontend, Backend & Data, Cloud, Tools & AI, and a quiet Engineering (legacy) row that keeps the structural thread honest.
  • The count-up — the footer tallies items and disciplines as the rows land, the way a schedule footer totals quantities.
Why a schedule: it expresses the theme without a single decorative line — the document type carries the metaphor. Software leads (Frontend / Backend / Cloud / AI sit first); the legacy structural tools are scheduled last, present but no longer load-bearing.

03 · How it draws & loops — the algorithm

A staggered reveal timeline + the shared draw primitive for the rules + an eased lerp for the count-up. All vanilla JS, one requestAnimationFrame per counter.

// 1 — THE SCHEDULE DATA  (grouped by discipline, tagged)
groups = [
  { tag:"FE", name:"Frontend",           items:[TypeScript, React, Next.js, React Native] },
  { tag:"BE", name:"Backend & Data",     items:[Python, PHP, Laravel, Convex, Supabase, SQL] },
  { tag:"CL", name:"Cloud",              items:[Cloudflare Workers] },
  { tag:"TL", name:"Tools & AI",         items:[Figma, GitHub, LangChain, Claude Code, Cursor] },
  { tag:"EN", name:"Engineering (legacy)", items:[AutoCAD, SAP2000, ETABS, SADS, MATLAB] },
]
// each item → row: TAG = `${g.tag}-0${i}`  e.g. BE-03 = Laravel

// 2 — RULE LINES via the DRAW PRIMITIVE  (plot on, never fade)
function drawRule(line, delay):
    L = line.getTotalLength()
    line.style.strokeDasharray  = L
    line.style.strokeDashoffset = L
    after(delay): line.transition("stroke-dashoffset .5s ease") → offset 0

// 3 — ROWS TALLY IN  (staggered timeline, top → bottom)
t = 0; STEP = 70ms
for row in orderedRows:            // subheaders + item rows, in document order
    after(t): row.classList.add("shown")   // opacity 0→1, slide 4px→0
    t += STEP                       // each row lands a beat after the last

// 4 — COUNT-UP  =  eased lerp 0 → value over a duration
function countUp(el, value, dur):
    start = now()
    function frame(t):
        p  = clamp((t - start) / dur, 0, 1)
        e  = 1 - (1 - p)³                // easeOutCubic — fast then settle
        el.text = round(value * e)
        if p < 1: requestAnimationFrame(frame)
    requestAnimationFrame(frame)

countUp("#cTotal",  totalItems,  900ms)   // 21 items
countUp("#cGroups", groupCount,  900ms)   //  5 disciplines

// 5 — RESPECT THE USER
if prefers-reduced-motion:
    show every row, draw rules at offset 0, set final counts — no timeline
The "draw" primitive (reused everywhere): L = path.getTotalLength(); dasharray = L; dashoffset = L → 0. The schedule's hairline rules use the exact same three lines as the hero spine and the Journey tower — so the table reads as if one plotter inked the whole set.
