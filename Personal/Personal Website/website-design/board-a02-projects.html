02 · What it means

  • Every project is a sheet — the mini title block borrows the drafting convention from the home hero, so the whole site reads as one engineer's drawing set.
  • The system diagram is the proof — nodes are the real pieces (Web, Edge, DB, Mobile, Portal, AI) and edges are how they connect. It shows the architecture at a glance, not just a logo wall.
  • Plot-on reveal — edges draw like a plotter when the card enters the viewport; nodes pop after. Motion earns attention exactly once per card, then stops.
  • Software leads, engineering frames — the copy is product & stack; the engineer-builder thread is reinforced by the Structural Automation sheet without taking over.
Why this works for Projects: a reader scans four sheets and instantly sees what each system is made of. The diagram is the differentiator — it says "I think in systems" without a single buzzword, and it ties straight back to the Structures → Systems theme.

03 · How it draws & loops — the algorithm

Each diagram is a tiny graph: nodes=[{id,x,y}], edges=[[a,b]]. An IntersectionObserver fires the draw once per card; hover re-runs it.

// 1 — DESCRIBE EACH SHEET AS A GRAPH  (data, not markup)
project = {
  title:"Buddy Ride", sheet:"P-01",
  nodes:[ {id:"Web",  x:40,  y:34},
          {id:"Edge", x:130, y:34},
          {id:"DB",   x:130, y:96},
          {id:"Mobile",x:40, y:96} ],
  edges:[ ["Web","Edge"], ["Edge","DB"],
          ["DB","Mobile"], ["Mobile","Edge"] ],
}

// 2 — BUILD THE SVG  (edges first, nodes on top)
for [a,b] in edges:
    line = svgLine(node[a], node[b])      // class .dgEdge
for n in nodes:
    g = svgNode(n.x, n.y, n.id)         // rounded chip + label, starts scale(.4) opacity 0

// 3 — THE DRAW PRIMITIVE  (the site's signature plot-on)
function plotOn(line, delay):
    L = line.getTotalLength()
    line.style.strokeDasharray  = L
    line.style.strokeDashoffset = L           // hidden, fully "un-plotted"
    requestAnimationFrame(() => {
        line.style.transition = `stroke-dashoffset .5s ${delay}ms ease`
        line.style.strokeDashoffset = 0       // L → 0 : it plots on, never fades
    })

// 4 — RUN THE CARD: edges stagger, then nodes pop
function runCard(card):
    edges.forEach((e,i) => plotOn(e.line, i * 130))     // stagger
    after(edges.length*130 + 250):
        nodes.forEach((n,i) =>
            pop(n.g, i*70))                       // scale .4→1, opacity 0→1

// 5 — TRIGGER ONCE ON SCROLL, RE-RUN ON HOVER
io = new IntersectionObserver(entries =>
        entries.forEach(en => {
            if (en.isIntersecting):
                runCard(en.target); io.unobserve(en.target)
        }), { threshold: 0.4 })
cards.forEach(c => io.observe(c))
cards.forEach(c => c.onmouseenter = () => runCard(c))   // (conceptually GSAP ScrollTrigger; here: vanilla IO)

// 6 — RESPECT THE USER
if prefers-reduced-motion:
    render every diagram complete, no observer, no hover loop
The "draw" primitive (reused everywhere): L = path.getTotalLength(); dasharray = L; dashoffset = L → 0. The home-hero spine, the Journey tower and these project edges are literally the same three lines of code — that's what makes the whole drawing set feel like one hand drew it.
