02 · What it means

  • Preliminary, on purpose — the cards sit slightly rotated on a dashed/papered ground so they read as sketches, not shipped product pages.
  • The rubber-stamp — CONCEPT / REV.A in muted engineer's red is the drawing-set tell: this is marked up, provisional, subject to revision.
  • The status tag — Exploring / Concept / Open says the honest truth about each idea at a glance, no overselling.
  • The wavy underline — a hand-drawn stroke under each title; it's the human hand on top of the technical chrome.
Why teasers only: the ideas wall shows direction and taste, not specs. Each card is a one-line concept plus an honest status — explorations, not commitments. Detail lives elsewhere, if and when an idea earns it.

03 · How it draws & loops — the algorithm

A hand-drawn underline is just a straight baseline with small fixed offsets on its control points — same path every replay, so it looks sketched, not random noise. The stamp is a CSS transform transition. No loop: a one-shot orchestrated reveal.

// 1 — BUILD A "HAND-DRAWN" UNDERLINE PATH  (wavy, but deterministic)
W = 220                                   // underline width (viewBox units)
baseY = 7
// fixed per-point jitter — NOT Math.random(); same every replay
jit = [ 0, -1.6, 1.2, -0.8, 1.7, -1.1, 0.6, 0 ]
function sketchPath(W):
    n  = jit.length
    pts = for i in 0..n-1:
            { x: i/(n-1) * W, y: baseY + jit[i] }
    // smooth the points into a single quadratic path
    d = "M" + pts[0]
    for i in 1..n-1:
        mid = midpoint(pts[i-1], pts[i])
        d  += "Q" + pts[i-1] + " " + mid   // control pt = prev point
    return d

// 2 — PLOT THE UNDERLINE ON  (the shared draw primitive)
function drawOn(path):
    L = path.getTotalLength()
    path.style.strokeDasharray  = L
    path.style.strokeDashoffset = L            // hidden: fully "rolled up"
    reflow()                                   // commit before transition
    path.style.transition  = "stroke-dashoffset .5s ease-out"
    path.style.strokeDashoffset = 0            // → 0 : the plotter draws it

// 3 — STAMP DROP  (rotate + scale via CSS transition, no draw)
// start state .anim : opacity 0, rotate(28deg) scale(2.1)
function stampIn(stamp):
    stamp.style.transition = "transform .42s cubic-bezier(.2,.8,.2,1), opacity .3s ease"
    stamp.classList.remove("anim")         // → rest: rotate(-7deg) scale(1), opacity .78

// 4 — ORCHESTRATE: one staggered reveal, card by card (no infinite loop)
function intro():
    for (card, i) in cards:
        setTimeout( () => stampIn(card.stamp), 120 + i*220 )
        setTimeout( () => drawOn(card.underline), 300 + i*220 )

// 5 — RESPECT THE USER
if prefers-reduced-motion:
    render one static frame: stamps at rest, underlines fully drawn, no transitions
The "draw" primitive (reused everywhere): L = path.getTotalLength(); dasharray = L; dashoffset = L → 0. The same three lines that plot the home-hero spine and the Journey tower draw these sketch underlines too — the only twist is a few fixed control-point offsets so the line reads as a hand, not a ruler.
