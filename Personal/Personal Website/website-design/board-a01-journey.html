02 · What it means

  • Foundation = engineering — the structure sits on Structural Engineering (39-storey towers). The origin isn't hidden; it's literally what everything else is built on.
  • Floors stack bottom→top — Fractal/Yeslend, Buddy Ride, then the contact-centre suite. Newest work is highest, so reading up is reading forward in time.
  • The column line — one accent load path threads every floor. It grows exactly with scroll, so the visitor feels themselves erecting the building.
  • Dimension lines — the left edge dimensions each floor by its year span, the engineer's habit of annotating a drawing rather than decorating it.
  • As-built, not rendered — this is the record drawing of a career: what was actually constructed, floor by floor, foundation to Now.
Why this is the centrepiece: it states the whole thesis in one motion — Structures literally becoming Systems. The foundation is concrete-and-steel; the upper floors are software. You don't read a timeline, you watch it stand up, and the engineering past reads as load-bearing rather than a footnote.

03 · How it draws & loops — the algorithm

One scroll listener throttled through requestAnimationFrame; progress drives the column line, and per-floor thresholds fire each reveal once. In production this is GSAP ScrollTrigger with scrub; the live demo runs on vanilla JS.

// 1 — FLOORS, bottom → top  (foundation first, roof last)
floors = [
  { tag:"FND", t:0.00, title:"Structural Engineering", yr:"2018–2021" },  // 39-storey towers
  { tag:"L1",  t:0.26, title:"Fractal · Yeslend + automation", yr:"2022–2025" },
  { tag:"L2",  t:0.48, title:"Buddy Ride · cross-border",     yr:"2024–2025" },
  { tag:"L3",  t:0.70, title:"Contact-centre suite",          yr:"2025–now"  },
  { tag:"ROOF",t:0.92, title:"Now",                           yr:"—"        },
]

// 2 — READ SCROLL PROGRESS of the inner frame  → p ∈ [0,1]
function progress():
    return scroll.scrollTop / (scroll.scrollHeight - scroll.clientHeight)

// 3 — GROW THE COLUMN LINE  (the load path) with p
//     same primitive as everywhere: a length we reveal, not a fade
function drawColumn(p):
    L = ghost.getTotalLength()            // full height of the structure
    col.style.strokeDasharray  = L
    col.style.strokeDashoffset = L * (1 - p)     // L→0 as p:0→1, plots upward

// 4 — REVEAL EACH FLOOR ONCE, when scroll crosses its threshold tᵢ
function checkFloors(p):
    for f in floors:
        if !f.built and p >= f.t:
            f.built = true
            plotOn(f.rule)      // level rule draws in  (dashoffset L→0)
            plotOn(f.dim)       // left dimension line draws in
            f.content.fadeUp()    // label + body translateY(8)→0, opacity→1

// 5 — THROTTLE with requestAnimationFrame (one read per frame, no jank)
ticking = false
scroll.onscroll = () =>
    if !ticking:
        ticking = true
        requestAnimationFrame(() => {
            p = progress()
            drawColumn(p); checkFloors(p); setPct(p)
            ticking = false
        })

// — PRODUCTION equivalent —
// gsap ScrollTrigger { trigger:frame, scrub:true } drives the same p.

// 6 — RESPECT THE USER
if prefers-reduced-motion:
    p = 1; drawColumn(1)         // full column, every floor built
    floors.forEach(buildInstantly)   // no scroll loop
The "draw" primitive (reused everywhere): L = path.getTotalLength(); dasharray = L; dashoffset = L → 0. The column line, every floor rule, every dimension line on this sheet — all the same three lines of code as the home hero's spine and orbits. Scroll just maps your position onto that one offset, so the structure plots on like a plotter instead of fading in. That's what makes it feel like one hand drew the whole site.
