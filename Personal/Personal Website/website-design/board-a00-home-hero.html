Orbital Spine — the landing hero

Your sketch, fused with the theme: a diagonal load-path spine (Structures) crossed by nested orbits (Systems). Nodes are the hub destinations and they orbit live. Below the demo: exactly how it draws and loops.

01 · Look & feel — live

Watch it load: the spine plots on first, orbits draw in, then the nodes start orbiting. Light Direction A, IBM Plex type, faint blueprint grid for atmosphere.

02 · What it means

  • The spine — the diagonal axis is a structural column line / load path. The through-line of your story; everything hangs off it.
  • The orbits — nested, tilted ellipses are the systems you build. They share one centre: you.
  • The nodes — four destinations (Journey, Projects, Writing, Ideas) ride the orbits. They're the actual nav — click a node to travel.
  • Scannable — left side stays calm text; the motion lives on the right so the hub reads in 5 seconds.
Why this works as the hub: it's the theme in one image — Structures (spine) meeting Systems (orbits) — and it doubles as navigation. The diagram is the message and the menu.

03 · How it draws & loops — the algorithm

Pure math + one requestAnimationFrame loop. The same primitive we reuse for every animated motif on the site.

// 1 — DEFINE THE ORBITS  (shared centre, nested, one tilt)
C    = { x: 700, y: 270 }            // the core = you
tilt = -26°
orbits = [
  { rx:120, ry: 50, speed: 0.22, t:0.3, label:"Journey"  },
  { rx:184, ry: 78, speed:-0.15, t:1.7, label:"Projects" },
  { rx:250, ry:106, speed: 0.10, t:3.0, label:"Writing"  },
  { rx:322, ry:136, speed:-0.07, t:4.6, label:"Ideas"    },
]   // alternating speeds → orbits counter-rotate (alive, not mechanical)

// 2 — A POINT ON A TILTED ELLIPSE  (parametric, the whole trick)
function pointOn(o, t):
    x = o.rx * cos(t)
    y = o.ry * sin(t)
    return rotate(x, y, tilt) + C

// 3 — INTRO: "PLOT ON", don't fade  (the theme's signature motion)
timeline:
    spine.draw(0.5s)                     // dashoffset L → 0
    orbits.draw(0.4s, stagger 0.15s)
    nodes.popIn()
    then → start loop()

// 4 — THE LOOP  (orbit forever, ~30s / revolution)
function loop(now):
    dt = (now - last) / 1000;  last = now
    for o in orbits:
        o.t += o.speed * dt
        moveNode(o.node, pointOn(o, o.t))
    requestAnimationFrame(loop)

// 5 — RESPECT THE USER
if prefers-reduced-motion:
    render one static frame, skip the loop
The "draw" primitive (reused everywhere): L = path.getTotalLength(); dasharray = L; dashoffset = L → 0. Dimension lines, the Journey tower, project diagrams — all the same three lines of code. That's what makes it feel like one hand drew the whole site.
