# Content Index

Use this area to turn research, brainstorming, project lessons, and personal ideas into publishable material.

## Pipeline

```text
idea or question
    -> research inbox
    -> topic note
    -> content brief
    -> blog draft
    -> social post variants
    -> publish log
    -> later update
```

Full workflow: [[Personal/Personal Website/content/content-workflow|Content workflow]].

## Where things live

| Folder | Purpose | Start here |
|---|---|---|
| `research-inbox/` | Capture raw ideas, links, questions, and observations quickly. | [[Personal/Personal Website/content/research-inbox/_readme|Research inbox]] |
| `topics/` | Develop one researched concept into a reusable source note. | [[Personal/Personal Website/content/topics/_readme|Topics]] |
| `drafts/` | Write blog posts, short notes, and social variants. | [[Personal/Personal Website/content/drafts/_readme|Drafts]] |
| `published/` | Keep a record of live URLs, dates, channels, and future refresh work. | [[Personal/Personal Website/content/published/_readme|Published content]] |
| `templates/` | Start new research, briefs, and social variants consistently. | [[Personal/Personal Website/content/templates/topic-research-template|Topic research template]] |

## Starter content pillars

These are hypotheses from the current experience. Keep, remove, or rename them after answering [[Personal/Personal Website/open-questions#Content]].

| Pillar | Example angles |
|---|---|
| Building practical software | Enterprise workflow lessons, frontend patterns, Cloudflare, realtime systems |
| Product and startup execution | What changes when you build across idea, design, code, and operations |
| Engineering across disciplines | Lessons carried from civil engineering into software and automation |
| AI-assisted development | Practical workflows, limits, and quality checks when using coding tools |
| Personal experiments and app ideas | Selected public build notes, research, and decisions |

## First action

Create one note in `research-inbox/` for a topic you already care about. Do not start by trying to write a polished blog post.
