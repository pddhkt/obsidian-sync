# Go Visual Prompt Bank

Use these prompts when generating lesson images. Keep a consistent style: clean flat educational diagram, light background, minimal labels, no code screenshot unless requested, no decorative clutter.

## Slice Window Over Array

Filename: `slice-window-over-array.png`

Prompt:

> Create a clean flat educational diagram showing a Go slice as a movable window over a backing array. Show a row of array cells labeled 0 to 5, then a highlighted slice window covering cells 1 to 3. Add small labels for "slice", "len", "cap", and "backing array". Minimal colors, white background, crisp vector-like style, no watermark.

## Pointer Address to Value

Filename: `pointer-address-to-value.png`

Prompt:

> Create a clean flat educational diagram showing a Go pointer. On the left, show a small label box named "taskPtr" containing an address like 0x01. Draw an arrow from it to a larger value box named "Task" with fields Title and Done. Minimal colors, white background, crisp vector-like style, no watermark.

## Interface Method Plug

Filename: `interface-method-plug.png`

Prompt:

> Create a clean flat educational metaphor for Go interfaces. Show an interface socket labeled "TaskStore: List(), Create()" and two different plugs labeled "MemoryStore" and "PostgresStore" fitting into it because they have matching methods. Minimal labels, white background, crisp vector-like style, no watermark.

## Error Value Two Paths

Filename: `error-value-two-paths.png`

Show one function box splitting into two paths: success path with "Task" and failure path with "error". Add a small caller box checking "if err != nil". Minimal colors, white background, crisp vector-like style, no watermark.

## Context Cancellation Signal

Filename: `context-cancellation-signal.png`

Prompt:

> Create a clean flat educational diagram showing context cancellation in a Go web request. Flow left to right: Browser request, Go handler, store query, database. Above the flow, show a red cancellation signal traveling through all steps. Label it "ctx.Done()". White background, crisp vector-like style, no watermark.
