# Imarflex Social-Card Style

Use this reference when the user wants results closer to `pitch/deck/assets/social-carousel-*.png`, or when the goal is visual exploration rather than strict production.

## Direction

The pitch-deck carousel examples are a designed social-card system, not plain product posters.

Core feel:

- Square-first feed cards.
- Energetic but still warm and practical.
- Strong Heritage Blue visual anchors.
- Saveable educational layout.
- Product/photo modules combined with graphic UI-like overlays.
- Designed template rhythm across frames.

## Visual Ingredients

Use several of these per frame:

- Large frame number: `01`, `02`, `03`, `04`, etc.
- Strong headline in Traditional Chinese.
- Short subtitle or supporting line.
- Heritage Blue corner circles, arcs, ribbons, or vertical rules.
- Cool Air airflow ribbons for fan/cooler topics.
- Dotted grid micro-patterns.
- Small line-icon rows.
- Callout chips/cards with short labels.
- Taped photo cards, paper notes, or collage fragments.
- CTA buttons for final frames: primary Heritage Blue button plus secondary Clay Beige/WhatsApp-style button.
- Small footer strip for benefits, icons, or trust notes.

Use the product/photo as one module in a graphic system, not always as a full poster hero.

## Format Rules

- Default exploration format: square `1:1`, because the pitch-deck examples are square.
- If the actual channel needs `4:5`, generate square masters only when comparing style, then create local 4:5 experiments or regenerate after choosing a direction.
- Keep copy short. Dense graphic cards work best when text is designed in layers, not paragraphs.
- For exact text-critical production, consider generating a no-text or low-text visual master and applying deterministic local typography/layout.

## Frame Patterns

| Frame Type | Social-Card Treatment |
|---|---|
| Hook | Big number, bold question headline, blue corner shape, product or product-outline ghost, 1-2 small proof icons |
| Product | Product/photo module, measurement/callout cards, small spec chips, warm still-life background |
| Explanation | Diagram panels, arrows/ribbons, numbered steps, icon cards |
| Benefit | 2-3 benefit cards, lifestyle/product hybrid, airflow or use-case illustration |
| Maintenance | Proof/demo layout, close-up crop, checklist/callout cards, clean part labels if exact |
| CTA | Large headline, product hero, primary CTA button, WhatsApp/support secondary button, benefit icon footer |

## Prompt Language

Use phrases like:

- "designed Instagram social card, not a calm product poster"
- "square feed-card template"
- "large frame number in Heritage Blue"
- "graphic layout system with product photo module, callout chips, icon row, blue corner shapes"
- "saveable educational carousel look"
- "taped photo-card collage elements"
- "CTA button shapes, but no fake URL or QR code"

Avoid phrases that over-flatten the layout:

- "generous empty negative space" unless deliberately testing minimal.
- "no clutter" without naming allowed graphic components.
- "pure Muji poster" when the user wants pitch-deck social-card energy.

## Exploration Sets

When testing possibilities, propose 2-4 directions:

| Direction | Use |
|---|---|
| Pitch-deck social card | Best match to existing deck carousel examples |
| Social-card editorial | More photo-led but still numbered/callout-driven |
| Bold diagram card | For comparison, airflow, specs, checklists |
| Calm premium poster | Legacy Muji/Kinfolk fallback |

Generate only one or two frames first to compare style before producing a full carousel.

## QA

- Does it feel like a social card, not just a product photo with text?
- Is there a repeatable frame system?
- Are numbers, callouts, icon rows, buttons, and blue shapes used intentionally?
- Does the product still match source references?
- Is all generated text exact or marked for local typography cleanup?
