# Hero SKU Selection Rubric

「Hero SKU」= 個 period 入面 **content concentration、conversion narrative、budget attention** 集中嘅單一 SKU(per category)。客戶問「下個月主推邊隻」嗰陣應該一句答得到 + 一句 reasoning。

呢條 rubric 將呢個決策由「直覺 / flagship 慣性」變成 transparent 嘅 6-軸 score,等 hero 選擇可以畀人 challenge、可以 cross-period audit、可以對得返 market scan 嘅 signal。

## The 6 dimensions(每軸 1-3 分,max 18)

| # | Dimension | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 1 | **Margin × Inventory** | 低 margin 或 stock 不穩 / 季尾清貨 only | 中 margin + 穩定 stock | 高 margin + 充足 stock + sustained ≥ 3 個月 |
| 2 | **Demand × Seasonal fit** | 反季 / 跌勢 / 冇 search demand signal | Evergreen 或單 source 升勢 | 多 source 確認嘅 in-season peak(market scan ≥ 2 source 同方向) |
| 3 | **Differentiation strength** | Commodity(對手齊有相同 spec / angle) | 1 個獨特 angle | ≥ 2 個獨特 angle 對手做唔到 |
| 4 | **Content readiness** | 冇 sample 冇 brief | 1 篇 sample / brief 排住 | ≥ 3 篇 content 本期可以圍住佢出 |
| 5 | **DTC moat fit** | Retailer 一樣賣到,冇 add-on | Warranty / parts-finder 加分 | Warranty + parts-finder + WhatsApp / 高 intent 多入口齊集 |
| 6 | **Brand reputation safety** | LIHKG / Reddit / 售後 channel 有負評累積(internal-only signal) | 中性 / 冇 noise | 自家 / 用戶 / 媒體有正面 mention |

> [!info] 證據程度 marker 仍然要標
> 任何一軸畀 score 之前,要標 ✅ / ⚠️ / 🟡。Pitch stage 大部分 Margin × Inventory 都會 ⚠️(等 client confirm)。Score 連 marker 都要紀錄,eg `M×I ⚠️ 2 / Demand ✅ 2 / Diff ✅ 3`。

## Pass thresholds

| Total | Action |
|---|---|
| **15-18 / 18** | ✅ **Hero this period**(寫入 focus doc 嘅 hero subsection) |
| **11-14** | Secondary / supporting SKU(可以 push 但唔做 content 主角) |
| **≤ 10** | 唔 push,留做 long-tail PDP / catalog 角色 |

## 3 anchoring rules

1. **One hero per category per period。** 4 個 SKU 同時做 hero = 冇 hero。Concentration > coverage。
2. **Hero must beat second-place by ≥ 3 分。** Gap 細(eg 16 vs 15)= 揀緊兩個都得,要再 think,可能兩個都係 secondary 而冇真 hero。
3. **任何一軸攞 1 分 = automatic DQ,即使其他軸高分。**
   - Margin 1 分 → push 完賺唔到錢
   - Demand 1 分 → 推出嚟冇人搜
   - Differentiation 1 分 → commodity 化,SERP / retailer 直接食晒
   - Content 1 分 → 出唔到 3 篇文,SEO + social 冇彈藥
   - DTC moat 1 分 → 同 retailer 打 price war 無贏
   - Brand safety 1 分 → push 緊負評,自殺式 marketing

## 4 quality tests(score 完之後跑)

| Test | 點驗 |
|---|---|
| **Concentration test** | 每個 active category 最多 1 個 hero?多咗 = 冇 hero,只係列 SKU |
| **Content-shippable test** | 寫得出本期至少 3 件 content 圍住個 hero?寫唔出 = Content readiness ≤ 2 分,score 重算 |
| **Pitch test** | Client 問「下期主推邊個 SKU」可一句答 + 一句 reasoning?答得遲緩 = 個 hero 唔夠 sharp,可能 score 假高 |
| **Replacement test** | Client 話「呢個 hero drop」,有冇 next-best?冇 = period plan 過於依賴單 SKU,要 dual-hero 或加 secondary |

## Pitfall list

| Pitfall | Signal | 修法 |
|---|---|---|
| **Spec-led 揀 hero** | 「機能最強」但客戶搜唔到 / 唔識用 | Demand 軸要對 market scan + search signal,唔可以淨係 spec sheet |
| **Margin-only 揀 hero** | 「呢個賺最多」但 commodity | Diff 軸 ≥ 2 先放行,否則 secondary |
| **Brand-name nostalgic** | 「flagship 一直係呢隻」但 reliability ⚠️ | Brand safety 軸做 gate;有負評就 DQ |
| **2-3 個 hero 平均分散** | 想多推幾隻 → 一個都唔深 | Concentration rule,迫住揀 1 |
| **冇配 content readiness** | 揀咗 hero 但本期出唔到 3 篇 | Content 軸 1 分 → score 自動 ≤ 13 → 走唔到 hero gate |
| **跨 period 連續同一 hero 無 refresh** | 半年 IRC-20IH 冇加新 angle | 每季 hero 至少要有新 angle / 新 content cluster,否則內容老化 |

## Worked example — IRC-20IH @ 2026-Q2

Score(post Q2 market scan):

| Dim | Marker | Score | Reasoning |
|---|---|---|---|
| 1. Margin × Inventory | ⚠️ | 2 | 旗艦定位,推測高 margin;⚠️ 實際 margin + 庫存 sustained 要 client confirm |
| 2. Demand × Seasonal fit | ✅ | 2 | IH 電飯煲全年 evergreen high intent;Q2 唔係 peak season 但唔係 reverse |
| 3. Differentiation strength | ✅ | 3 | (a) 中容量 1.5–2.2L gap — scan 確認 Pana/Toshiba 集中喺 0.45–1.0L mini range;(b) 日工藝 + DTC moat 多 angle |
| 4. Content readiness | ✅ | 3 | Buying guide sample 已備 + carousel sample 已備 + 可加保養文(已有 fan 保養 sample 結構可 reuse) |
| 5. DTC moat fit | ✅ | 3 | 2 年保養登記 + parts-finder + WhatsApp 高 intent 都接得返 |
| 6. Brand reputation safety | ✅ | 3 | 冇 LIHKG 負評,媒體 listicle 缺席但唔係負評(係 mindshare 弱問題) |
| **Total** | | **16 / 18** | ✅ **HERO** |

Quality tests:
- Concentration ✅ — 只揀 IRC-20IH 做 IH category hero
- Content-shippable ✅ — buying guide + carousel + 中容量 angle 第二篇 = 3 件
- Pitch ✅ — 一句答:「IRC-20IH,主打中容量 IH gap」
- Replacement ✅ — IRC-22KS 13/18 secondary 可頂替

## Worked example — 降糖 IH 一般 SKU @ 2026-Q2

| Dim | Marker | Score | Reasoning |
|---|---|---|---|
| 1. Margin × Inventory | ⚠️ | 2 | TBD |
| 2. Demand × Seasonal fit | ✅ | 2 | 健康角度有需求 |
| 3. Differentiation strength | ❌ | **1** | **Commoditised** — Toshiba RC-10IRPH 35% sugar reduction + Thanko 都已採用,scan 證實已係 HK SKU-level standard |
| 4. Content readiness | ⚠️ | 1 | 冇 dedicated 降糖 sample |
| 5. DTC moat fit | ✅ | 3 | 同上 |
| 6. Brand reputation safety | ✅ | 3 | OK |
| **Total** | | **DQ** | ❌ Drop hero status — Diff 1 分自動 DQ |

降糖 IH **唔可以做 hero**。要做就要搵 specific USP(米種 / 內膽 / 食療 angle)再 re-score。

## How to use in focus doc

1. List 每個 active category 嘅 candidate SKU(eg IH 有 IRC-20IH / IRC-22KS / 降糖 generic / 其他)
2. 每個 candidate 用上面 6-dim table score 一次,marker + 分 + reasoning 都要寫低
3. Apply pass threshold + DQ rules
4. 只有 ≥ 15/18 + 無 DQ 嘅 SKU 寫入 focus doc 嘅 hero subsection
5. Score 結果直接 paste 入 focus doc 嘅 `有冇新品 / 清貨 / 高 margin SKU?` section,做 audit trail
6. Cross-period:下季寫 focus 時要 read 上季 hero score,如果係連續第 2 個季同一 hero,**必須加新 content cluster / 新 angle**(避免老化)

## When this rubric does NOT apply

- 寫 PDP 寫 blog 寫 social caption 揀講邊個 SKU — 嗰個係 `imarflex-copywriter` 嘅範圍,by-content,唔涉及 period-level hero 決策
- Long-tail SKU 嘅 catalog ranking / SEO — 唔需要 6-dim,屬於 SEO research scope
- 客戶 ad-hoc 推某 SKU promo — 如果係 client commercial decision,記錄返做 ⚠️ exception,唔逼住 rubric pass
