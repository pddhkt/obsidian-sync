## A1)訂單 export — 後台直接出,format 跟 Imarflex 月結 template 預設

**簡單講:做到,而且 format 由 Imarflex 話事。** 同事可以喺後台一 click export 訂單,出 CSV / Excel,columns 同排序按 Imarflex 月結 report 嘅 template 預先 set 好,出嚟即用,唔需要再手動 reformat。

### 後台 export 包括嘅嘢

- **訂單列表 export** —— 揀日期範圍(例如:上個月 1 號至月尾)、訂單狀態(已出貨 / 已完成 / 退換)、付款方式、客戶來源(D2C / 豐澤 / 百老匯等)。
- **Columns 自選 + saved preset** —— 例如月結常用嘅 columns(訂單編號、日期、客戶、產品、數量、總額、付款方式、發票編號、運費、折扣、實收)可以 save 做一個 preset,以後一 click 出。亦可以同時保留另一個「客服 / 退換」preset,睇 case 切換。
- **CSV + Excel(.xlsx)兩種格式** —— Excel preset 可以連埋 header 樣式、欄寬、freeze pane,打開即可以拎去做月結。
- **小計 / 分組統計可選** —— 例如按「客戶來源」分組 subtotal、或按「產品分類」分組 — 唔需要再喺 Excel 度做 pivot。
- **發票編號 / 付款 reference 同步** —— Airwallex 嘅 transaction reference 直接拉入 column,對數對得返。

### 同 Shopline 對比

| 項目 | Shopline export(現況) | 新網站後台 export |
|---|---|---|
| Columns 排序 | 固定 / 限制揀 | 完全自訂 + saved preset |
| 格式 | 純 CSV,要再開 Excel reformat | CSV + .xlsx(連格式) |
| 小計 / 分組 | 冇,要 Excel 自己做 pivot | 後台可直接出 |
| 月結 template | 每次手動對 | 一次 set 好,以後一 click |
| 多 preset | 冇 | 有(例如月結 / 客服 / 退換各一) |

> 想 confirm 一樣嘢:**Imarflex 而家做月結用嘅 columns 同 layout 係點?** 如果可以 share 一份現用嘅 Excel template(或者列一列要嘅 columns),我哋直接喺後台 set 做預設 preset,Imarflex 同事第一日用就唔需要再 reformat。

呢個包喺 3.1 retainer 嘅日常範圍,唔額外收費。

## B1)O365 全公司 migration + 新 laptop SSO setup — 分開講邊 part 做到

**坦白講,呢件事要分兩 part 答**:

### 我哋做到嘅 part:**Microsoft 365 tenant / mailbox migration**

呢部分屬 SaaS 範疇,正正係我哋日常處理嘅嘢(domain / DNS / SSL / email hosting 同類)—— 上次 B1 都有列。具體包:

- **新建 / 整理 Microsoft 365 tenant**(`@imarflex.com` 同任何 alias domain),配對 DNS、MX、SPF、DKIM、DMARC,確保 email 寄出寄入無損。
- **現有 mailbox 數據 migration** —— 由現時嘅 email 平台(Shopline mail / Gmail / 舊 O365 tenant,睇實際情況)將每個同事嘅 mail、contacts、calendar 搬入新 tenant。
- **同事帳號 / 權限 setup** —— 開 user account、分 license、set group / distribution list、共享 mailbox(例如 `cs@`、`sales@`、`info@`)、autoresponder。
- **OneDrive / SharePoint 基本 setup** —— 每位同事個人雲端、公司共用文件夾結構、基本權限分配。
- **基本安全 baseline** —— MFA 強制開、conditional access(只限信任地點 / device)、admin account 同日常 account 分開、外寄 mail policy。
- **交接文件 + 1 節 admin training** —— Imarflex 內部 admin(or Derek 直接)點日後自己加 / 移 user、改 password、reset MFA 等。

### 唔係我哋強項嘅 part:**新 laptop 採購 + 同事 endpoint setup**

老實講,新 laptop 揀型號 / 採購議價 / 開箱 image / 同事桌面 software install / 印表機驅動 / 內部 Wi-Fi / VPN —— **呢啲屬 office IT 硬件範疇,唔係我哋強項**,上次 B1 都有講。

具體上**我哋唔接**:

- 揀 laptop 型號 / 議價 / 採購 / 收貨。
- 開箱、裝 Windows / macOS image、裝 Office app、裝其他公司 software(會計、設計、Adobe 等)。
- 同事到場 / 上門 onsite 換機、搬資料、教用法。
- Office Wi-Fi、router、printer、共用 NAS、VPN 設定。

呢部分**比較適合本地 office IT support / managed service partner** 接 —— Imarflex 如果未有,可以由 Derek 或 office manager 直接揀一間,我哋唔抽佣亦唔負責 coordinate(免得日後出事責任唔清)。我哋嘅 O365 tenant set 好之後,本地 IT 同事 / partner 喺 laptop 上落 user account 同 SSO 係好直接嘅事,通常半個鐘一部機。

### Endpoint SSO —— 中間地帶

「laptop SSO setup」呢一句要再分清楚:

- **如果指「新 laptop 用同事個 O365 account 登入 Windows / Mac」** —— 呢個係 endpoint 落 account 嘅操作,**通常由裝機個 IT 同事直接做**,我哋 tenant 嗰邊 enrol policy 配合得到(會喺交接文件寫清楚)。
- **如果指「公司其他 SaaS(例如 Adobe、會計、Shopline admin、CRM)經 O365 SSO 登入」** —— 呢部分**我哋可以接,但要逐個 app 睇支唔支援、有冇 license tier 限制、要唔要加 Azure AD / Entra ID Premium**。要先列 Imarflex 而家用緊嘅 SaaS list,再逐個評估。
