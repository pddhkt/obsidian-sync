# 報價問題跟進回覆 — 2026-05-28

> 多謝跟進,以下逐條答覆 board meeting 後嘅兩條問題。

## A1)11 月前上線 — 做得到,而且有 buffer

**做得到。** 由今日(5 月底)起算,11 月前上線**有大約 5 個月 runway**,而 Phase 1 + Phase 2 加埋只需 **7–10 週實際工作時間**。即係話,中間有約 **2–3 個月 buffer** 處理素材延誤、內部 review、節日 / 假期、軟上線觀察期等。

### 建議時間表

| 階段 | 期間 | 工作 | Imarflex 需配合 |
|---|---|---|---|
| **啟動 + Discovery** | 6 月初 — 6 月中(~2 週) | Kickoff meeting、確認 scope final、收齊啟動素材 8 項 | 簽報價單 + 50% 訂金、提供素材(見下) |
| **Phase 1 · 設計 + 開發** | 6 月中 — 8 月初(5–7 週) | UI / UX 設計、Next.js + Payload CMS 開發、Airwallex 整合、後台 customise | 設計稿 review(2 輪)、後台 walkthrough 一節 |
| **Phase 2 · 遷移 + 上線測試** | 8 月初 — 8 月底(2–3 週) | Shopline 完整 migrate、301 redirect、email 自動化、上線測試 | 確認產品 / 訂單 / 客戶數據準確、UAT 1 週 |
| **軟上線 + 觀察** | 9 月初 — 10 月中(~6 週 buffer) | 新站 live、監察訂單 / 付款 / 排名、跟 bug、admin training | 同事 admin training 1–2 節、日常用後台、回報問題 |
| **正式 launch 推廣期** | 10 月中 — 11 月初 | SEO 內容上線、首輪 promo campaign、社交配合 | 確認 launch 推廣方向 |

> 即係話:**8 月底已經可以軟上線,11 月之前正式 launch 完全 doable**,中間仲有兩個月 buffer。

### 6 個關鍵 milestone(Imarflex 要配合嘅節點)

呢啲節點如果準時,11 月前上線冇問題;如果其中一兩個 delay,buffer 啱啱好食得起。**全部 delay 過 2 週**先會壓到上線期。

1. **6 月初 — 簽報價單 + 50% 訂金 + Kickoff meeting**
    - 簽完 → 我哋即刻開工,設計同開發並行起步。
2. **6 月初 — 提供啟動素材 8 項**(已列喺附件條款 — 包括:現有產品 list / CSV、產品高清相、品牌素材 / logo source、Shopline admin 唯讀權限、domain DNS 控制權、現任 / 同事聯絡點、Brand voice 喜好參考、現有 KPI baseline)。
3. **6 月底 — 設計稿確認**(2 輪 major revision 內)
    - 設計 sign-off 後我哋進入開發中段,**支付中期 30%**。
4. **7 月底 — 後台 walkthrough + UAT 開始**
    - Imarflex 同事(尤其操作組)上後台試,我哋按 feedback 收 final tuning。
5. **8 月底 — 軟上線 / 上線交付 + 尾數 20%**
    - 新站 live、開始接訂單;首兩週密切監察。
6. **9–10 月 — Admin training 1–2 節 + SEO 內容啟動**
    - 全包 retainer 喺呢個時間 kick in,首 6 個月免費試用期開始計。

### 風險點(我哋已經喺 buffer 入面 cushion 咗)

|---|---|---|

## A2)Budget 壓力 — 可以分階段,但 Phase 1 + 2 要一齊做

**坦白講:Phase 1 同 Phase 2 係上線嘅前提,呢兩個冇得分開做** —— 因為冇 migration + 301 redirect 就唔可以由 Shopline 切換過嚟。但**Phase 1 + 2 入面嘅 scope 可以收窄做「核心 MVP 上線」,將部分 enhancement 推遲做 Phase 1.5,慢慢加上去**。

即係話分兩個層次:

- **必須 bundle 嘅:** Phase 1 + Phase 2 整體 launch(冇辦法只做設計唔做開發、或者開發完唔做 migration)。
- **可以分階段嘅:** Phase 1 + 2 入面嘅 feature scope —— 邊啲一定上線當日要齊、邊啲可以上線後再 ship。

### 「核心 MVP 上線」vs「Phase 1.5 enhancement」對照

| 項目 | 核心 MVP<br/>(上線必要) | Phase 1.5 enhancement<br/>(上線後 ship) | 點解咁分 |
|---|---|---|---|
| **網站 + 後台** | ✓ 完整前後台 | — | 上線前提 |
| **Airwallex checkout(FPS / 信用卡)** | ✓ | — | 上線前提 |
| **Airwallex AlipayHK / WeChat / 分期** | 信用卡 + FPS 起步 | AlipayHK / WeChat / 分期分期後加 | HK 客戶 80%+ 用 FPS / 信用卡,其餘可以慢加 |
| **200+ SKU migration** | ✓ 全部 | — | 上線唔可以剩半個 catalog |
| **301 redirect** | ✓ 全套 | — | SEO 保命,慢做會掉排名 |
| **PDP / 分類頁 / checkout / 客戶帳戶 / 訂單追蹤** | ✓ | — | 上線基本功能 |
| **Email 自動化 — order confirmation / shipped** | ✓ 基本 2 個 trigger | 其餘 6 個 trigger(棄單追回、保養提醒、win-back 等)分階段加 | 訂單通知一定要有;進階自動化遲少少出唔影響運作 |
| **保養登記表單(線上 register)** | ✓ 基本表單 | 進階會員 cross-sell 流程 | 收 email 起步,後期再做 nurture flow |
| **後台 dashboard 6 個** | ✓ 必要 3 個(訂單 / 庫存 / 客戶) | 進階 3 個(CRO / SEO / 內容表現) | 日常運作需要嗰 3 個一定要齊 |
| **進階 admin features**(bulk edit、批量上架、報表 export 自訂) | 基本上架 / 改價 / 出貨 | 進階功能 | 日常用得到嘅先做 |
| **CRO / A/B test 工具** | — | ✓ 全包 retainer 啟動後做 | retainer 啱啱 start 嘅嘢,唔影響上線 |
| **門市搜尋頁 / Store locator** | — | ✓ 上線後 1–2 週內加 | 上線當日無亦唔阻運作 |

> 簡單講:**上線當日要有「客戶可以買嘢、訂單可以入、Imarflex 同事可以處理」呢三條核心**;其餘進階 feature 可以分批 ship,客戶肉眼通常都唔察覺。

### 兩條收 budget 嘅實際路徑

| 路徑 | 點操作 | 慳到幾多 | Trade-off |
|---|---|---|---|
| **路徑 1 — 核心 MVP 上線,Phase 1.5 後期分批加** | Phase 1 + 2 照付(HK$50,000),但開發 scope 收窄到核心 MVP;Phase 1.5 enhancement 喺上線後分 2–3 個 milestone 加,每個 milestone HK$5,000–10,000 按範圍。 | 一筆過支出唔變,但**現金流壓力分散**;Phase 1.5 部分若覺得唔需要可以唔做(慳全 HK$10,000–20,000)。 | 上線當日部分進階 feature(AlipayHK / 8 trigger 自動化等)未齊;通常客戶唔察覺。 |
| **路徑 2 — 推遲 retainer 第 7 個月起付,先用免費 6 個月** | Phase 1 + 2 照付(HK$50,000);全包 retainer **首 6 個月免費** 期間照出 blog + 做 SEO + 內容更新;第 7 個月起先決定續用邊個 tier(全包 ~HK$2,500 / 月 或 bare 3.1 HK$1,000 / 月)。 | 首 6 個月 retainer **HK$0**(慳 ~HK$15,000);7 個月後睇實際數據先 commit。 | 唔需要 trade-off —— 試用期本身就係冇 commitment 嘅機制。 |

> **兩條路徑可以一齊行** —— 核心 MVP 上線 + Phase 1.5 分批加 + retainer 免費試用 6 個月。三樣加埋,**頭半年實際支出主要集中喺 Phase 1 + 2 嘅 HK$50,000**,其餘嘅嘢分階段慢慢加 / 試完先 commit。

### 坦白講邊啲我建議唔好 cut

呢個 scope 我哋睇過好多次,有幾樣**慳得唔抵**,值得提出嚟:

- **301 redirect 全套** —— 慳一千幾百但會掉 SEO 排名,新站排名要重建 6–12 個月。
- **Core Web Vitals 滿分 + 性能優化** —— 直接影響 conversion rate,Phase 2 入面已包,唔好 trim。
- **Admin training 同錄影 walkthrough** —— 上線後同事用得順唔順,training 決定。已包,唔需要 cut。
- **首兩週軟上線監察** —— 上線後一定有 edge case bug,唔做監察會影響真實訂單。

> 一句:**結構 / SEO / 監察呢類「上線基礎」唔好慳,進階 feature(8 trigger email、AlipayHK、CRO 工具)分批加完全 OK。**
