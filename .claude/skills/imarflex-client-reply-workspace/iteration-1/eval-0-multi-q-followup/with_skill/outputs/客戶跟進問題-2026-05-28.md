# 客戶跟進問題 — 2026-05-28

> 來源:Derek Chong, WhatsApp, 2026-05-28
> 註:同事 review proposal 後再追問,集中喺後台權限、產品 PDF 管理、同澳門 cross-border 三個方向。

---

## A. 網站 / 後台跟進

### A1)後台支唔支持多 user + role permission?
> 「個試用 admin 啱啱試咗,想知支持唔支持多 user 同 role permission?例如客服同事得睇訂單但唔可以改價,marketing 同事可以寫 blog 但唔可以改產品 spec — 呢類 access control 做唔做到?」

### A2)PDP 上 PDF 說明書 / 保養手冊嘅上載同顯示
> 「我哋部分產品有 PDF 說明書同保養手冊,客戶買咗會想自己 download。新後台有冇位俾我哋上載同管理呢類 PDF 文件,然後喺 PDP 顯示俾客戶?」

### A3)中長期擴展去澳門 — 多 currency / 地址 / 運費邏輯
> 「中長期我哋想擴展去澳門做 cross-border,同一個 site 處理唔同 currency / 地址格式 / 運費邏輯做唔做到?」

### 對齊決定

| # | 問題 | 方向 |
|---|---|---|
| A1 | 多 user + role permission | 做到 — custom CMS 內置 role-based access control;列出 3 個 ready-made roles(Admin / 客服 / Marketing)+ 可按需要自訂;唔額外收費 |
| A2 | PDF 說明書 / 保養手冊 | 做到 — 後台「文件管理」位,可掛喺產品,PDP 自動顯示 download section;包喺 3.1 retainer 內 |
| A3 | 澳門 cross-border | 架構支持(multi-currency / region / shipping zone);坦白分:而家 build 內 vs 之後加;HK$ + MOP$ + 澳門地址 + 運費分區做到;真正 cross-border tax / 跨境物流 partner 等運營層另議 |
