## A1)訂單 export 月結 report — 同事自己一 click 搞掂,format 預先度好

**得 —— 而且可以將 export format 預先按 Imarflex 嘅月結 template 度身整定,同事唔需要再手動 reformat。**

而家 Shopline 出嚟嗰啲 generic format 之所以難用,係因為平台只能出佢預設嗰幾欄,Imarflex 月結需要嘅欄位 / 順序 / 小計 / 分類往往要再執。新後台呢度可以直接解決:

### 後台直接做到嘅

- **同事自己 export** —— 後台「訂單」頁面有 export 掣,揀日期範圍(本月 / 上月 / 自訂)→ 一 click 出 CSV 或 Excel(.xlsx)。
- **預先度好 export template** —— 我哋會同 Imarflex 會計 / 月結同事傾一次,睇下而家 reformat 緊邊啲嘢(欄位順序、合併單元格、分類小計、總計、稅項計算等),將呢啲規則直接寫入後台 export,出嚟嗰刻已經係月結用嘅 format。
- **可以同時出幾個 view** —— 例如同一個月可以分別 export:
  - **會計入帳 view**(訂單日期、訂單號、客戶、產品、數量、單價、總額、付款方式、運費、稅項)
  - **出貨 / 物流 view**(訂單號、收件人、地址、產品 SKU、數量、運單號)
  - **產品銷售 view**(按 SKU 統計賣咗幾多、收幾多)
- **直接俾會計師 / 內部報表用** —— 出嚟可以直接 import 落 Imarflex 嘅會計系統(QuickBooks / Xero / MYOB / 自家 Excel template 等),唔使再人手執。

### 點 set up

1. 上線前(或上線後第一個月結之前),我哋同 Imarflex 月結同事**約 30 分鐘**,睇實際 Shopline export 出嚟之後執成點、最後落手俾會計嗰份 template 係點 —— 將「人手執嘅每一步」收集齊。
2. 將呢啲規則直接寫入後台 export logic,同事下次 export 出嚟已經係最終 format。
3. 之後每月,同事自己 click 一次,**完。**

> 即係話:**人手 reformat 嗰步直接消失。** 而呢個 setup **包喺 3.1 月度 retainer 內**,唔另收費 —— 屬於「為 Imarflex 度身整嘅後台」嘅一部分。日後想加多一個 view、或者改 format(例如會計師換咗 template),通知我哋執一執就得。

## B2)O365 全公司 migration + laptop SSO setup — 想坦白講清楚 scope

呢條我想直接答,因為 Imarflex 急住下個月內要搞掂,如果我哋夾硬接,反而會拖到 timeline。

**坦白講:呢個 project scope 入面有大半唔係我哋接得嘅工種。** 上次 B1 已提過框架,呢度按你今次嘅實際需求再分清楚:

### 邊啲我哋接得(SaaS / web / 雲端一面)

- **Microsoft 365 tenant 開立 + domain verification + DNS 設定**(MX / SPF / DKIM / DMARC / Autodiscover)
- **Mailbox migration 規劃**(由現有 email provider 搬到 Exchange Online,包括歷史 email、calendar、contacts)
- **Microsoft Entra ID(前 Azure AD)用戶建立 + group / permission 結構**
- **SSO 嘅 web / SaaS 一面** —— 將 Entra ID 接駁去其他 SaaS(例如新網站 admin、Airwallex、PostHog 等),用 O365 帳號單一登入
- **Sharepoint / OneDrive 共享資料夾結構規劃 + 權限設定**
- **MFA / Conditional Access policy 設定**(由邊啲 IP / device 可以登入、要唔要 2FA)
- **OneDrive backup 規劃**(同事舊 laptop 上嘅檔案點搬過去)

### 唔係我哋強項(屬 office IT / hardware / onsite 工種)

- **逐部新 laptop 開箱、裝 Windows / O365 client、enroll 落 Intune / MDM**(全公司咁多部要逐部做)
- **每位同事個人 setup**(登入、舊資料 migrate、打印機、Wi-Fi、本地 software 安裝)
- **同事日常 IT support**(壞機、忘記密碼、software 安裝、辦公室 Wi-Fi / 內網 troubleshoot)
- **辦公室 hardware / 內網 / printer / 多功能機 / 會議室器材**

呢部分需要**有同事可以親身去 Imarflex office 同每個同事位逐個 setup** —— 即係屬本地 IT MSP(managed service provider)嘅日常工種,唔係我哋呢類 web / 軟件公司嘅 setup。

### 我哋唔開呢張報價嘅原因

老實講,如果我哋夾硬報一個全包價接落嚟,然後 sub 出去俾人做 device 一面,中間多咗一層 coordination,**Imarflex 既要俾 mark-up,timeline 又會慢過直接搵 MSP**。對 Imarflex 唔抵。

### 建議點行

分兩條 track 平行,下個月內絕對搞得掂:

| Track | 邊個做 | 內容 |
|---|---|---|
| **Track A — Device / onsite** | **本地 IT MSP**(Imarflex 自己搵 / 既有 vendor) | 新 laptop 採購 / 開箱 / OS + O365 client 安裝 / 同事位 setup / 培訓 / 日後 day-to-day IT support |
| **Track B — O365 tenant / SaaS / SSO** | **我哋** | Tenant 開立、domain / DNS、mailbox migration、Entra ID 結構、SSO config、Sharepoint / OneDrive 結構、MFA policy |

兩條 track 之間嘅交接(例如 SSO config 點俾 MSP 落去每部 laptop 嘅 Entra ID join 設定),**我哋同 MSP 直接對接技術細節**,Imarflex 唔需要做中間人。

### 我哋 Track B 嘅工作量同收費

如果 Imarflex 想我哋做 Track B,大致工作量同收費:

| 項目 | 內容 | 工時 / 收費(參考) |
|---|---|---|
| Tenant 開立 + DNS / MX / SPF / DKIM / DMARC | 半日 setup + verification | 一次性 ~HK$2,500 |
| Mailbox migration(假設 < 30 個 mailbox) | 規劃 + 試一個 + batch migrate + verify | 一次性 ~HK$5,000–8,000(視乎舊 provider) |
| Entra ID 結構 + group / permission | 同事架構落 group,設權限 | 一次性 ~HK$2,500 |
| SSO 接 SaaS(每個 app 計) | 每個 SaaS app 接 Entra ID | ~HK$800 / app |
| MFA / Conditional Access policy | 全公司 policy + 試行 | 一次性 ~HK$2,500 |
| Sharepoint / OneDrive 結構 | 共享資料夾規劃 + 權限 | 一次性 ~HK$3,000 |

> 上面係參考價,**實際要等 MSP 揀好、知道部署 / 同步 timeline 之後**,我哋先正式報。因為 Track A 同 Track B 嘅工序有 dependency(例如 MSP 點 enroll device 會影響我哋 Entra ID 設邊啲 policy),嘥時間估冇用。
