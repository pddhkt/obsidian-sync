## B1)Phase 拆做 —— 真正可以慳嘅位係 Phase 3 + add-on,Phase 1+2 拆唔到

呢條問題答之前,**坦白講**有兩件事要分清楚:

### 點解 Phase 1 + Phase 2 拆唔到

Phase 1(設計 + 開發,$40k)同 Phase 2(Shopline migration + 上線,$10k)**係同一件事嘅前後段** —— 唔起好新站,根本 migrate 唔到、上唔到線、收唔到單。

- Phase 1 = 起間屋
- Phase 2 = 搬屋入伙 + 通水通電

兩件分開做冇意思 —— 起好間屋唔搬入去,間屋就吉住、未上線、未收得單。所以**呢 $50k 係上線最低門檻**,係 launch ticket。

### 真正可以拆 / 慳嘅位

**Phase 3(月度 retainer)同 add-on(reviews / chatbot / blog / live chat 等)係另一回事 —— 呢啲完全可以「先上線、後加」。** 而且報價單上 Phase 3 retainer **首 6 個月已經免費**,即係上線後**冇額外現金流壓力**。

| 項目                            | 報價       | 上線必要? | 可以延後加? |
| ----------------------------- | -------- | ----- | ------ |
| **Phase 1** 設計 + 開發            | $40,000  | ✅ 必要  | ✗ 拆唔到  |
| **Phase 2** Migration + 上線     | $10,000  | ✅ 必要  | ✗ 拆唔到  |
| **Phase 3** 月度 retainer        | 首 6 個月免費 | ⚪ 建議  | ✓ 上線後決定 |
| **全包 retainer**(blog / SEO 引擎) | 首 6 個月免費 | ⚪ 可選  | ✓ 上線後決定 |
| Reviews / Loyalty / Referral  | 另議 SOW   | ✗ 唔必要 | ✓ 任何時間加 |
| AI Chatbot / Live chat        | 另議 SOW   | ✗ 唔必要 | ✓ 任何時間加 |
| Blog 內容 / SEO content pack    | 另議 SOW   | ✗ 唔必要 | ✓ 任何時間加 |

### 推薦路線:MVP-first,上線後睇數據再 add

**第 1 步(必做):Phase 1 + Phase 2 — $50k**
ship 一個完整、可以正常運作、可以收單嘅新網站。所有報價單列出嘅嘢都 included(custom CMS、Airwallex、PostHog、SEO 基礎、email 自動化、Shopline migrate)。

**第 2 步(免費 6 個月試 retainer):**
上線當日起,**全包 retainer 首 6 個月免費**(value ~HK$15,000) —— 試用期內持續出 blog、做 SEO、交 social caption。Imarflex 用實際流量、轉化、訂單數據判斷:
- 試完覺得抵 → 繼續 ~$2,500 / 月
- 覺得 blog / SEO 部分用唔到 → 轉去 3.1 bare retainer $1,000 / 月(只係維護 + 上架更新)
- 完全唔想要 → 收 case 計

**第 3 步(完全有彈性,話加就加):**
上線跑咗幾個月,睇實際數據再決定加邊個 add-on:
- Reviews 多人問 → 加 review system
- 客服 inbox 開始爆 → 加 AI chatbot / live chat
- SEO 開始有 organic traffic → 加 blog content pack

呢啲全部係**獨立 SOW**,加邊個就計邊個,**冇套裝壓力**。

### 即係話 Imarflex 短期實際要出嘅錢

- **上線之前:HK$50,000**(分 50% / 30% / 20% 三期付,見原報價單)
- **上線後首 6 個月:HK$0**(retainer 免費)
- **第 7 個月起:HK$1,000 – $2,500 / 月**(睇試完之後揀邊個 tier)
