# AI 產品文案生成 (Add-on)

## 解決咩問題
- 200+ SKU,人工寫文案太慢
- 文案質素參差,tone 唔統一
- 新品上市拖到 launch 慢

## 帶嚟咩好處
- 新品上架快 5-10x (幾日 → 幾分鐘)
- Tone 統一 (AI 跟 brand voice guideline)
- 多版本 A/B test (一個產品生 3 版)

## 點 work
- Admin 入後台 → 輸入產品 spec / 賣點
- AI 自動生成: 標題、benefit、PDP 文案、SEO meta、social caption
- 編輯改 → publish

## 適合幾時加
**Q2-Q3** — Launch 後新品開始 backlog 嗰陣
早加意義唔大,因為 launch 嗰批 SKU 反正要人工 review

## 報價
- Setup: HK$5,000-10,000
- API 費: ~HK$200-500/月

## Pitch 講法
> 「200 個 SKU 寫文案,人手要 2 個月。AI + 編輯 review 模式,2 週搞掂,而且 tone 完全統一。」
