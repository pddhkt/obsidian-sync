# Loyalty 系統 (Add-on)

## 解決咩問題
- 重複購買率低 — 客戶買完就走
- 配件 / 新機 cross-sell 冇 incentive
- 高價值客戶冇識別 / 獎賞,易流失去競爭對手

## 帶嚟咩好處
- 重複購買率 +20-30%
- AOV +15% (達下個 tier motivation)
- 客戶分層 (Silver / Gold / Platinum)
- 整合 [[referral-program]] + [[reviews-system]] + [[warranty-registration]] (全部 driver 行為都可以 reward 分數)

## 適合幾時加
**Q3 最理想** — 已有一年數據,知邊啲行為值得獎勵
- 太早加效果差 (基數細)
- 太遲加錯失重複客

## 報價
- Setup: HK$10,000-20,000
- 月費: $0 (自家系統)
- **包含 [[referral-program]]**

## 點 work
- 積分機制 (每 $1 = 1 分)
- 3 級 (Silver / Gold / Platinum)
- Tier 行為: 購買、review、referral、保養登記
- Redemption: 折扣、免運、專屬產品

## Pitch 講法
> 「Loyalty 唔係折扣,係客戶分層工具。你會睇到邊批客貢獻 80% 銷售,然後針對性服務佢哋。」
