# _system — timeless definitions

The parts of the sales-content system that do **not** belong to any month: assumptions, taxonomies, and templates. Everything period-bound lives in [[../cycles/_readme|cycles/]].

## What lives here

- [[assumptions]] — strategy assumptions, evidence level, how to validate
- [[topic-types]] — 8 repeatable content topic types
- [[sales-purposes]] — 6 sales purposes used for tracking
- [[topic-sales-matrix]] — topic type → sales purpose → IG/FB example → CTA → ad fit
- [[post-card-template]] — template for one content item record

## Do NOT put here

- Monthly plans, targets, post records, reviews → `../cycles/yyyy-mm/`
- Workflow process docs → `online-marketing/` root (`content-storage-system`, `topic-research-workflow`, `channel-production-workflow`)
