# Sales Content Posts

Create one Markdown note per content item here. These notes power [[../../_sales-content.base]].

## Status values

| Status | Meaning |
|---|---|
| idea | Captured, not approved |
| planned | Approved for a week/month |
| drafting | Being produced |
| draft-ready | Content exists but is not published |
| scheduled | Scheduled to publish |
| published | Live post |
| archived | No longer active |

## Required frontmatter

- `type: sales-content-post`
- `content-level`: `campaign` or `social-post`
- `status`
- `publish-month`
- `publish-week`
- `channel`
- `format`
- `topic-type`
- `sales-purpose`
- `product-category`
- `destination`
- `primary-cta`
- `ad-support`

## Naming

For campaign bundles, use:

```text
yyyy-mm-wx-short-topic.md
```

Example:

```text
2026-06-w1-rice-cooker-capacity.md
```

For individual IG / FB posts, use:

```text
yyyy-mm-dd-channel-short-topic.md
```

Example:

```text
2026-06-12-ig-rice-capacity-table.md
```
