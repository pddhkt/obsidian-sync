## How The Original Angles Were Built

The angles appear to come from a structured chain, not only copywriting intuition:

1. **Content pillars** from the spreadsheet: product focus, usage/recipe, tips/maintenance, brand/trust.
2. **Product feature extraction** from the Products sheet:
   - ICF-140R: 14L tank, ice/ice crystal support, mist/humidified airflow, honeycomb cooling system, strong airflow, timer, filter, mobility, warranty.
   - IFQ-22R: vortex/air circulation, 3D/all-direction airflow, easy-clean detachable parts, remote, timer/modes, warranty.
3. **Consumer problem framing**:
   - ICF: Hong Kong summer is hot/humid, aircon is costly, user wants local comfort.
   - IFQ: aircon feels uneven, one side is cold while corners stay hot, user wants circulation.
4. **Format choice**:
   - ICF became a carousel because it needs education: situation -> product -> feature proof -> price/CTA.
   - IFQ became a single-frame post because its core promise can be understood quickly: circulate air better with one product.
5. **Trust/CTA layer**: price, 2-year warranty, official product image, product-page / service CTA.
6. **Brand/layout layer**: one image one benefit, feature pills, product center, price/CTA at bottom, cool blue palette.

Important: the output pack contains useful angle thinking, but some claims are not publish-safe as written. Current July copy should keep the angle logic while using current spec-confirmation rules.

## Recommended Content Thinking Flow

Use this before writing or revising each post:

```text
Customer problem
-> Product promise
-> Feature proof
-> Trust proof
-> CTA / next action
```

Do not start from "list all specs". Start from what the buyer is trying to solve, then choose the minimum set of features that proves the product is relevant.
