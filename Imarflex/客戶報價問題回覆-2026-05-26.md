## A3)新網站 × FB / IG / 官方 Online shopping 嘅互動關係

完全認同 —— 而家 FB / IG 嘅流量的確比品牌網站多,所以**唔係要分開行,係要互相 feed**。

### 角色分工

| Channel                            | 角色                              |
| ---------------------------------- | ------------------------------- |
| **新網站**                            | Brand HQ / 內容源頭 —— 完整產品資料、blog、品牌故事、自家 checkout |
| **FB / IG**                        | Discovery 入口 —— 帶 traffic 入網站 / PDP |
| **Online shopping**(Shopline / 新網站) | 落單 conversion 終點(依 Q2 揀 Option A 或 B) |

### 點樣 feed 入網站

- **每篇 blog 文章 ship 配套 IG / FB caption + 配圖**(上次 Q3 已提過,呢度重申係已包嘅 deliverable)。
- **所有社交 post 嘅 product link 都帶 UTM tag** —— PostHog 即時見到邊個 channel(FB / IG / WhatsApp / email)帶幾多 traffic、邊條 post 轉化最好。
- **PDP / blog 有 share button**(WhatsApp / Messenger / 複製連結)—— 鼓勵客戶自己分享。
- **新網站 SEO 排名上去之後**,Google search 帶嚟嘅 organic traffic 會慢慢追上 / 超過社交 —— 因為 SEO 係**永久資產**,而社交 post 喺 feed 兩日就沉。長線兩個 channel 平衡發展。

### Online shopping 點 fit 入嚟

新網站本身有自家 checkout(經 Airwallex 處理 FPS / 信用卡 / AlipayHK / WeChat),**唔需要將客戶送去 Shopline 落單**。
- 揀 **Option A**(過渡期):Shopline 同新網站並行,FB / IG 主要帶 traffic 入新網站。
- 揀 **Option B**(直接取代):Shopline 退役,新網站係唯一 online shopping。

### 社交媒體日常運營(scheduling / 回覆 / community management)

我哋目前嘅 scope 係**提供內容**(隨 blog 出 caption + 圖,跟品牌 voice 寫),**唔包括日常 scheduling、回 message、community management**。如果日後 Imarflex 想由我哋接手呢部分,可以**另行報價 social ops retainer** —— 但唔屬而家報價範圍。

## A4)點樣令實體門市客戶都得益?

呢個係好重要嘅問題 —— 新網站唔係淨係 online shopping 工具,亦係**橋接 offline 客戶嘅入口**。

### 而家已經 / 即將實裝嘅橋接機制

1. **PDP「邊度買」section** —— 每個產品頁都會顯示「直接購買 / 豐澤 / 百老匯 / 實惠」並列。D2C 放第一,實體連結並列,**唔強推 online,客戶自己揀**。PostHog 追蹤點擊分佈,睇邊類客戶傾向去邊度。
2. **保養登記(warranty registration)** —— 實體門市買嘅客戶可以線上 register 保養,**收集 email / 聯絡資料 → 入會員 → 未來 email / 推廣可以接觸返**。過去得一張紙保養卡,而家可以做返 CRM。
3. **Blog / 食譜 / 選購指南嘅 CTA 唔限 online** —— 部分文章 CTA 可以係「去最近門市試機」、「實體睇實物」、「打電話查實體 stock」—— 唔係每篇都推 online 落單。
4. **QR code 配合實體 leaflet / POP / 包裝**(配合 B2)—— 實體傳單、POP、產品包裝可以印 QR code,掃描去 PDP / 食譜 / 保養登記 / 會員註冊。**等實體門市客戶都有理由「掃一掃」入網站**,慢慢轉化做有聯絡資料嘅客戶。
5. **Email list / 推廣同步影響 online + offline** —— 用同一個會員 list 推新品、優惠、活動。Promo code 可以「網店 / 實體都通用」,driver 客戶兩邊行。

### 仲可以加埋嘅嘢(都包,唔另收)

除咗上述 5 個橋接機制之外,如果 Imarflex 想,我哋仲可以加埋:

- **門市搜尋頁 / Store locator** —— 按地區搜門市、地圖、電話、營業時間。新網站直接整一頁,客戶搵實體店方便啲。**呢個我哋包埋,唔額外收費**。

> 老實講「offline 點得益」係一個值得傾深啲嘅 topic —— 上面列嘅係技術上做到嘅 hook,但**真正放大效果嘅係營運上點配合**(例如門市同事點引導客戶 scan QR、保養登記點變成日後 cross-sell 機會、實體 promo 同 online promo 點同步等)。
>
> 我哋好樂意同 Imarflex sales / 門市同事**開一節 brainstorm**,一齊諗點將實體 + online 串埋一齊行 —— 任何時候話聲就安排。
