Step 1 · Business focus

每個 category 一個 hero。 紀律咁揀,唔係靠熱情。

兩層 model:季度 focus = thesis(category + DTC moat)。月度 focus = bet placement(今月 promo / 內容 / 同季度 diff)。 兩者都由 6 軸 hero SKU rubric 撐住。

季度 focus
Thesis(每 3 個月改一次)
推邊個 category · 每個 category 嘅 hero SKU · DTC moat · 季節 arc · evergreen pillar。 Output:yyyy-qx-focus.md
月度 focus
Bet placement(每月改)
今月實際 promo · 推緊邊啲 SKU · ship 緊邊啲 content · 同季度 diff reconciliation table · 今月 out of scope list(必填)。 Output:yyyy-mm-focus.md
月度必填嘅兩個 section Diff from quarter focus + Out of scope this month 存在係要 catch 靜雞雞 drop 嘅 bug。 真實例子:Q2 focus 押咗抽濕機,monthly 靜雞雞 drop 咗。 Audit 揪返出嚟。 新規則強制每個決定都見得到。

俾 ChatGPT、Perplexity、Claude cite — 唔單止係 Google rank。

5 軸 rubric。 過關 = 13/15。 任何軸 = 1 + 內容涉及 health / safety / electrical → auto-DQ。

04 · Hard rule — skill file 自己 enforce,唔淨係靠團隊自覺

三條 — 就算 client 提出我哋都唔會破。

規則同時 mirror 喺幾個 skill + agent file + persistent memory。 多層 enforcement 保證 session 同 session 之間、agent 同 agent 之間,行為一致。

1
LIHKG / Reddit / 論壇 sentiment 只留內部
永遠唔入 brief、blog、PDP、social、pitch deck、任何 client-facing deliverable。 只可 aggregate sentiment(eg「過去 90 日 N 條 thread 提及痛點 X」)。 只計 Imarflex 自己嘅 brand mention — 競品 brand sentiment 永遠唔 surface。

點解:法律 risk(quote 用戶冇同意)。 E-E-A-T penalty(Google 2026-03)。 Brand 信譽 risk,如果用競品 sentiment 做 marketing ammunition。
2
唔可以 fake citation 或 false schema fact
每個 claim 都有 URL + 日期 + source。 AEO auditor reject「according to X report」但冇 URL 嘅 content。 Schema 只 declare PDP 實際支援嘅嘢 — 冇 fake aggregateRating、冇 stale price、冇 false stock status。

點解:Google 罰 false structured data。 Brand 信譽。 LLM hallucination 會將 false claim 放大成 AI 搜尋 answer — 規模化錯誤。
3
Pitch-stage 誠實 — 未 measure 前唔承諾 lift
Pitch 階段我哋 show 方法論、唔 sell promises。 ⚠️-heavy 喺 scan output 屬正常(冇 client data)。 唔講「我哋幫你 lift X% traffic」 — 我哋 show 點 measure、然後誠實 measure。

點解:信任。 Client 簽約前可以驗證方法論嚴謹度。 同時消除我哋 fake baseline 嘅誘因。
