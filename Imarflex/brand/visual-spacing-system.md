# Spacing System / 間距系統

> ⚠️ Placeholder — 待設計階段最終 confirm。

## 預想 scale (8px base)

| Token | px | Use |
|---|---|---|
| `space-1` | 4 | Tight gap |
| `space-2` | 8 | Inline gap |
| `space-3` | 12 | Compact stack |
| `space-4` | 16 | Default |
| `space-6` | 24 | Section divider |
| `space-8` | 32 | Component margin |
| `space-12` | 48 | Page section |
| `space-16` | 64 | Hero |
| `space-24` | 96 | Page block |

## Container widths
- `narrow` — 640px (article)
- `default` — 1024px (most pages)
- `wide` — 1280px (PDP, dashboards)
- `full` — 100% (hero, banners)

## Grid
- 12-column on desktop
- 4-column on mobile
- 24px gutter (= space-6)
