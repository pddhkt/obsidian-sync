# brand/scripts

Python scripts that generate brand assets (e.g. logo-usage example PNGs and stand-in logo masters) into `../assets/`.

## What lives here

- Generation scripts (`.py`) that render brand-primitive artwork programmatically.

## Do NOT put here

- The rendered output — that goes to `../assets/`.
- Post/carousel render templates (Node) — those live in `../templates/`.
