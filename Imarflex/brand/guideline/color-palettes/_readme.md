# Color Palettes

Canonical Imarflex color tokens + hex (the single source of truth for palette values) plus client-facing palette boards.

## What lives here

- `Imarflex Color Palette.md` — canonical token + hex definitions (Heritage Blue / Rice White / Clay Beige / Steam Grey / Soft Charcoal / Cool Air …).
- `imarflex-color-palette-overview.png`, `imarflex-color-palette-pairings.png` — client palette boards.

## Do NOT put here

- **Logo files do NOT belong here.** The duplicate `imarflex-mark.png` / `imarflex-wordmark.png` that previously sat here were removed (2026-06-09) — the canonical copies live in `../Logos/`. Keep only palette boards + the palette `.md` here.
- The working draft `brand/visual-color-palette.md` should link to this file for hex values rather than restating them (this file is the canonical hex source).
