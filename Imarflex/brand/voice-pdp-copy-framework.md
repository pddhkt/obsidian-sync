# PDP Copy Framework / 產品文案格式

每 PDP 跟一致 5 段格式:

1. **Hook** — 一句問題 / scenario
   > 例:「煲開飯成日燶底?」
2. **Benefit** — 解決方法
   > 例:「IH 加熱均勻,飯粒粒分明」
3. **Spec** — 技術支撐
   > 例:「10 層厚釜內膽 / 24 小時預約」
4. **Trust** — 保養 + Trade-in
   > 例:「2 年保養 + 舊機回收 voucher」
5. **Social proof** — Reviews
   > 例:「★ 4.8 / 327 評價」(配合 [[reviews-system]] add-on)

## 例:IRC-20IH 電飯煲

| 段 | 文案 |
|---|---|
| Hook | 「煲開飯成日燶底?粒粒鬆唔到?」 |
| Benefit | 「IH 環繞加熱,每粒米均勻受熱,飯粒分明唔黐底」 |
| Spec | 「10 層厚釜內膽 + 6 段火力 + 24 小時預約」 |
| Trust | 「2 年原廠保養 + 舊機回收 HK$200 voucher」 |
| Social proof | 「★ 4.8 / 327 個香港家庭信賴」 |
