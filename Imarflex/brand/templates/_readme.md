# brand/templates

Code-based post/carousel render templates (Node `render.mjs` + `tokens.css`) that overlay text/diagram layers onto AI scene plates.

## What lives here

- `render.mjs`, `tokens.css` — the render pipeline.
- `carousel/` + `carousel/_proof/` — template config and rendered proof output.

## Do NOT put here

- Final delivered social art → `../social-samples/` (reference samples) or `../../online-marketing/sales-content/<campaign>/assets/` (campaign output).

> ⚠️ This folder holds active work but is currently **untracked in git** — add it so the renderer isn't lost.
