# Moodboard / 視覺方向參考

> ⬜ Placeholder — 等 reference images drop 入呢個 folder。
> 攝影方向規則去 [[brand/visual-photography-style]]。

---

## 🎯 Purpose

呢個 folder 唔係 final marketing asset,係 **視覺方向 reference** — 設計師、攝影師、image-gen prompt writer 用嚟對齊「日本起點 · 香港日常」嘅 mood。

放入嚟嘅圖應該幫到答呢啲問題:
- 光線應該點?(自然 / 柔光 / 角度)
- 背景應該點?(木紋 / 米色 / 廚房 tile)
- Styling 應該點?(飯碗 + 筷子 / 蒸氣 / 真實生活痕跡)
- 顏色情緒應該點?(配 [[Brand Guideline/Color Palettes/Imarflex Color Palette|Heritage Blue palette]])

---

## 📥 應該放啲咩入嚟

| Type | Example | Note |
|---|---|---|
| 產品攝影 ref | 日式無印電器、Balmuda lifestyle shot | 跟 [[brand/visual-photography-style]] §產品攝影 |
| Lifestyle ref | 香港家居廚房、自然光 morning scene | 跟 [[brand/visual-photography-style]] §Lifestyle 攝影 |
| 色調 ref | Pinterest / 雜誌 page、配 palette tokens | 配 [[Brand Guideline/Color Palettes/Imarflex Color Palette|color palette]] |
| Typography ref | 日式 editorial layout、雜誌跨頁 | 跟 [[brand/visual-typography]] |
| Material ref | 陶土 / 木 / 棉麻 texture | 對應 Clay Beige / Rice White mood |

---

## 📋 Naming convention

`moodboard-{topic}-{source}-{nn}.{ext}`

例:
- `moodboard-kitchen-pinterest-01.jpg`
- `moodboard-product-balmuda-02.jpg`
- `moodboard-color-mood-magazine-03.jpg`

---

## ⚠️ Usage rules

> [!warning] 唔好做
> - 唔好直接攞 moodboard 圖做 marketing 出街(嗰啲係 reference,有版權)
> - 唔好加西方節日 cliché(Christmas、Thanksgiving family scene)
> - 唔好擺 HDR / 過 saturated 圖做 ref
> - 唔好擺 stock-model 嘅圖

> [!tip] 要做
> - 每張 ref 配一行 caption 講「呢張我地想學咩」(光線 / styling / color / typography)
> - 同 [[brand/social-samples/_index|social-samples]] 對齊 — moodboard 係 direction,social-samples 係 generated 出嚟嘅 final ref

---

## 📂 Suggested sub-organization

當圖多咗,可以分子 folder:

```
Moodboard/
├── product/        ← 產品攝影 mood
├── lifestyle/      ← 家居 / 廚房場景
├── color/          ← 色調 / palette mood
├── typography/     ← 字體 / layout
└── material/       ← 材質 / texture
```
